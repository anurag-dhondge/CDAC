# 📘 Algorithms & Data Structures – Sessions 1, 2 & 3

**Course:** CDAC – CMCE / PGCP-AC  
**Batch:** August 2026  
**Subject:** Algorithms and Data Structures Using Java  
**Sessions:** 1, 2 & 3  
**Duration:** 6 Theory + 6 Lab Hours

---

## 📚 Topics Covered

### 1. Introduction to Problem Solving & Computational Thinking
- Introduction to problem-solving techniques
- Computational thinking
- Breaking problems into smaller tasks
- Logical thinking and algorithm development

### 2. Algorithm Constructs
- Sequence
- Selection (if-else)
- Iteration (loops)
- Understanding algorithm flow

### 3. Complexity Analysis of Algorithms
- Introduction to algorithm analysis
- Time Complexity
- Space Complexity
- Big O Notation
- Best, Average and Worst Case Analysis
- Complexity analysis of loops and recursive algorithms

### 4. Object-Oriented Design – Abstract Data Types (ADTs)
- Introduction to Abstract Data Types
- Data abstraction
- Operations and behaviour of ADTs
- Basic ADT examples

### 5. Basic Data Structures

#### Arrays
- Introduction to Arrays
- Array operations
- Insertion, deletion and traversal

#### Stack
- LIFO (Last In, First Out)
- Push operation
- Pop operation
- Peek operation
- Stack implementation using arrays

#### Queue
- FIFO (First In, First Out)
- Enqueue operation
- Dequeue operation
- Front and Rear concepts

#### Circular Queue
- Introduction to Circular Queue
- Front and Rear management
- Enqueue and Dequeue operations
- Efficient space utilization

---

## 💻 Lab Practicals

1. Implement Stack using Array.
2. Analyse the time complexity of loops.
3. Analyse the complexity of recursive algorithms.
4. Implement Queue with insertion at different locations:
   - First (Front)
   - Last (Rear)
5. Implement Circular Queue.

## ⚡ Important Concepts for Revision

| Concept | Key Point |
|---|---|
| Algorithm | Step-by-step procedure to solve a problem |
| Big O | Describes the growth rate of an algorithm |
| ADT | Defines data and operations without specifying implementation |
| Array | Collection of elements stored using indexed positions |
| Stack | LIFO principle |
| Queue | FIFO principle |
| Circular Queue | Queue that reuses empty spaces through circular indexing |

## 📊 Common Time Complexities

| Complexity | Name |
|---|---|
| O(1) | Constant |
| O(log n) | Logarithmic |
| O(n) | Linear |
| O(n log n) | Linearithmic |
| O(n²) | Quadratic |
| O(2ⁿ) | Exponential |
