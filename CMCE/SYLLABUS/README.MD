# 📚 CMCE – August 2026 Batch | Syllabus & Study Resources

Welcome to the **CMCE August 2026 Batch** repository!

This repository contains the subject-wise syllabus, learning resources, practical assignments, coding exercises, notes, and preparation materials for our batch.

The syllabus is based on the **ACTS, Pune – PGCP-AC August 2026 Suggested Teaching Guidelines**.

The goal of this repository is to maintain all academic resources in one place and help students with consistent learning, practical implementation, revision, and examination preparation.

## 🗂️ Subject-wise Syllabus

### 1. ☕ Object Oriented Programming with Java

<details>
<summary><b>Topics Covered</b></summary>

- Introduction to Java and JVM Architecture
- Basic Programming Concepts
- Object-Oriented Programming (OOP)
- Classes, Objects, Constructors and Methods
- Static Members and Object References
- Memory Management and Records
- Inheritance and Polymorphism
- Packages, Access Control and Type Casting
- Wrapper Classes and String Handling
- Enumeration, Sealed Classes and Inner Classes
- Abstract Classes and Interfaces
- Garbage Collection
- Exception Handling
- File I/O and Serialization
- Object Class and Date-Time API
- Generics
- Java Collection Framework
- List, Set and Map
- Comparable and Comparator
- Functional Programming
- Lambda Expressions and Method References
- Java Stream API
- Multithreading and Synchronization
- Concurrent Collections
- Reflection and Metadata
- JDBC and Transaction Management
- DAO Design Pattern

**Java Version:** Java 17 (LTS)

**Duration:** 60 Theory + 60 Lab + 30 Self Learning Hours

</details>

### 2. 🌐 Web Programming Technologies

<details>
<summary><b>Topics Covered</b></summary>

- Architecture of Web and Internet
- HTTP, HTTPS and Web Servers
- HTML5 and HTML Forms
- CSS, Flexbox and Grid
- Responsive Web Design
- Tailwind CSS
- JavaScript Fundamentals
- ES6+ Features
- JavaScript OOP and Functional Programming
- DOM Manipulation and Events
- Form Validation and Regular Expressions
- JSON
- TypeScript
- Fetch API and Axios
- Node.js Fundamentals
- Asynchronous Programming
- Callbacks, Promises and Async/Await
- Node.js Modules and npm
- Express.js and Middleware
- RESTful Web Application Concepts
- React.js
- React Components and Props
- React Hooks
- State Management and Context
- React Forms and Events
- Custom Hooks
- React Router
- Error Boundaries

**Technologies:** HTML5, CSS3, JavaScript, Tailwind CSS, TypeScript, Node.js, Express.js, React.js

**Duration:** 60 Theory + 60 Lab + 30 Self Learning Hours

</details>

### 3. 🧠 Algorithms and Data Structures Using Java

<details>
<summary><b>Topics Covered</b></summary>

- Problem Solving and Computational Thinking
- Algorithm Analysis and Big O Notation
- Abstract Data Types (ADTs)
- Arrays, Stacks and Queues
- Circular Queues
- Linked Lists
  - Singly Linked List
  - Doubly Linked List
  - Circular Linked List
- Recursion
- Trees and Tree Traversals
- Binary Trees and Binary Search Trees
- AVL Trees
- Searching Algorithms
  - Linear Search
  - Binary Search
- Sorting Algorithms
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Heap Sort
  - Merge Sort
  - Quick Sort
- Hash Functions and Hash Tables
- Collision Resolution Techniques
- Graphs and Graph Representations
- BFS and DFS
- Dijkstra's Algorithm
- Floyd-Warshall Algorithm
- Minimum Spanning Trees
- Prim's and Kruskal's Algorithms
- Algorithm Design Techniques
  - Divide and Conquer
  - Greedy Algorithms
  - Dynamic Programming
  - Brute Force
  - Backtracking
  - Branch and Bound
  - Stochastic Algorithms
- Time and Space Complexity

**Programming Language:** Java

**Duration:** 45 Theory + 45 Lab Hours

</details>

### 4. 🗄️ Database Technologies

<details>
<summary><b>Topics Covered</b></summary>

**MySQL / SQL**

- Introduction to DBMS
- Relational and NoSQL Databases
- Database Design and ER Diagrams
- SQL Command Categories (DDL, DML, DCL, TCL)
- Database Normalization (1NF, 2NF, 3NF, BCNF)
- Functional Dependencies
- Constraints and Data Types
- Aggregate Functions
- GROUP BY and HAVING
- Joins and Relational Algebra
- Subqueries and Correlated Subqueries
- Window Functions
- Common Table Expressions (CTEs)
- Views and Indexes
- ACID Properties and Storage Engines
- Stored Procedures and Functions
- Cursors
- Triggers
- Error Handling and Exception Management

**MongoDB / NoSQL**

- Introduction to NoSQL
- CAP Theorem and BASE Model
- Types of NoSQL Databases
- MongoDB Architecture
- Documents and Collections
- JSON and BSON
- CRUD Operations
- Query and Update Operators
- Projection, Sorting and Pagination
- Indexing
- Aggregation Pipeline

**Technologies:** MySQL, MongoDB, MySQL Workbench, MongoDB Compass

**Duration:** 30 Theory + 30 Lab + 30 Self Learning Hours

</details>
