## 1. Introduction to Inheritance

**Inheritance** is an important feature of Object-Oriented Programming (OOP) that allows one class to acquire the properties and behaviours of another class.

It supports **code reusability**, extensibility and hierarchical classification.

- **Base Class / Parent Class:** The class whose properties are inherited.
- **Derived Class / Child Class:** The class that inherits properties from another class.

### Syntax

```cpp
class Base {
    // Data members and member functions
};

class Derived : access_specifier Base {
    // Additional members
};
```

### Example: Basic Inheritance

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Dog is barking" << endl;
    }
};

int main() {
    Dog d;

    d.eat();   // Inherited function
    d.bark();  // Own function

    return 0;
}
```

**Output:**
```text
Animal is eating
Dog is barking
```

## 2. Types of Inheritance

C++ supports five major types of inheritance.

| Type | Description |
|---|---|
| Single | One derived class inherits from one base class. |
| Multiple | One derived class inherits from multiple base classes. |
| Multilevel | A class inherits from another derived class. |
| Hierarchical | Multiple derived classes inherit from one base class. |
| Hybrid | Combination of two or more types of inheritance. |

### 2.1 Single Inheritance

One derived class inherits from one base class.

<pre>
    Animal
       |
      Dog
</pre>

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Eating..." << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Barking..." << endl;
    }
};

int main() {
    Dog d;
    d.eat();
    d.bark();

    return 0;
}
```

**Output:**
```text
Eating...
Barking...
```

### 2.2 Multiple Inheritance

One derived class inherits from two or more base classes.

<pre>
    Father      Mother
        \        /
         \      /
          Child
</pre>

```cpp
#include <iostream>
using namespace std;

class Father {
public:
    void fatherProperty() {
        cout << "Father's property" << endl;
    }
};

class Mother {
public:
    void motherProperty() {
        cout << "Mother's property" << endl;
    }
};

class Child : public Father, public Mother {
public:
    void ownProperty() {
        cout << "Child's property" << endl;
    }
};

int main() {
    Child c;

    c.fatherProperty();
    c.motherProperty();
    c.ownProperty();

    return 0;
}
```

**Output:**
```text
Father's property
Mother's property
Child's property
```

### 2.3 Multilevel Inheritance

A class inherits from another derived class, creating an inheritance chain.

<pre>
    Grandfather
         |
       Father
         |
        Son
</pre>

```cpp
#include <iostream>
using namespace std;

class Grandfather {
public:
    void showGrandfather() {
        cout << "Grandfather class" << endl;
    }
};

class Father : public Grandfather {
public:
    void showFather() {
        cout << "Father class" << endl;
    }
};

class Son : public Father {
public:
    void showSon() {
        cout << "Son class" << endl;
    }
};

int main() {
    Son s;

    s.showGrandfather();
    s.showFather();
    s.showSon();

    return 0;
}
```

**Output:**
```text
Grandfather class
Father class
Son class
```

### 2.4 Hierarchical Inheritance

Multiple derived classes inherit from one common base class.

<pre>
          Animal
          /    \
       Dog      Cat
</pre>

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Dog is barking" << endl;
    }
};

class Cat : public Animal {
public:
    void meow() {
        cout << "Cat is meowing" << endl;
    }
};

int main() {
    Dog d;
    Cat c;

    d.eat();
    d.bark();

    c.eat();
    c.meow();

    return 0;
}
```

**Output:**
```text
Animal is eating
Dog is barking
Animal is eating
Cat is meowing
```

### 2.5 Hybrid Inheritance

Hybrid inheritance is a combination of two or more types of inheritance.

A common example is the diamond inheritance structure.

<pre>
          Person
          /    \
     Student  Employee
          \    /
        TeachingAssistant
</pre>

```cpp
#include <iostream>
using namespace std;

class Person {
public:
    void displayPerson() {
        cout << "Person class" << endl;
    }
};

class Student : virtual public Person {
};

class Employee : virtual public Person {
};

class TeachingAssistant : public Student, public Employee {
};

int main() {
    TeachingAssistant t;
    t.displayPerson();

    return 0;
}
```

**Output:**
```text
Person class
```

## 3. Virtual Base Class

A **virtual base class** is used in multiple inheritance to avoid duplicate copies of a common base class.

It solves the **Diamond Problem**.

### What is the Diamond Problem?

When two classes inherit from the same base class and another class inherits from both, the final derived class may receive two copies of the common base class.

<pre>
          A
         / \
        B   C
         \ /
          D
</pre>

Without virtual inheritance, class `D` receives two copies of class `A`.

### Solution: Virtual Base Class

Use the `virtual` keyword while inheriting the common base class.

```cpp
#include <iostream>
using namespace std;

class A {
public:
    int value = 100;

    void display() {
        cout << "Value: " << value << endl;
    }
};

class B : virtual public A {
};

class C : virtual public A {
};

class D : public B, public C {
};

int main() {
    D obj;

    obj.display();

    return 0;
}
```

**Output:**
```text
Value: 100
```

**Important Points:**
- Virtual inheritance avoids duplicate base-class subobjects in diamond inheritance.
- Only one shared virtual base-class subobject exists in the most-derived object.
- It removes ambiguity when accessing the common base-class members.

## 4. Constructors in Derived Class

A constructor is a special member function that initializes an object.

When an object of a derived class is created:

1. Base class constructor executes first.
2. Derived class constructor executes next.
3. When the object is destroyed, the order is reversed.

### Example: Constructor Execution Order

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base Constructor" << endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived Constructor" << endl;
    }
};

int main() {
    Derived obj;

    return 0;
}
```

**Output:**
```text
Base Constructor
Derived Constructor
```

### Parameterized Constructor in Derived Class

A derived class can call a parameterized base-class constructor using the **initializer list**.

```cpp
#include <iostream>
using namespace std;

class Person {
public:
    string name;

    Person(string n) {
        name = n;
        cout << "Person Constructor" << endl;
    }
};

class Student : public Person {
public:
    int rollNo;

    Student(string n, int r) : Person(n) {
        rollNo = r;
        cout << "Student Constructor" << endl;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Roll No: " << rollNo << endl;
    }
};

int main() {
    Student s("Anurag", 101);
    s.display();

    return 0;
}
```

**Output:**
```text
Person Constructor
Student Constructor
Name: Anurag
Roll No: 101
```

**Important:** The base class constructor must be called through the derived class's initializer list when the base class does not have an accessible default constructor.

## 5. Access Specifiers in Inheritance

C++ provides three inheritance access modes.

| Base Class Member | Public Inheritance | Protected Inheritance | Private Inheritance |
|---|---|---|---|
| Public | Public | Protected | Private |
| Protected | Protected | Protected | Private |
| Private | Not directly accessible | Not directly accessible | Not directly accessible |

### Example

```cpp
class Base {
public:
    int a;

protected:
    int b;

private:
    int c;
};

class Derived : public Base {
public:
    void display() {
        a = 10;  // Accessible
        b = 20;  // Accessible

        // c = 30; // Not directly accessible
    }
};
```

**Remember:**
- Public members are accessible according to the inheritance mode.
- Protected members are accessible inside derived classes.
- Private members cannot be accessed directly by derived classes.

## 6. Friend Function

A **friend function** is a non-member function that can access the private and protected members of a class when declared using the `friend` keyword.

### Example

```cpp
#include <iostream>
using namespace std;

class Demo {
private:
    int num = 100;

public:
    friend void display(Demo);
};

void display(Demo obj) {
    cout << "Number: " << obj.num << endl;
}

int main() {
    Demo d;
    display(d);

    return 0;
}
```

**Output:**
```text
Number: 100
```

**Important Points:**
- A friend function is not a member of the class.
- It can access private and protected members.
- It is called like a normal function.
- It is declared inside the class using `friend`.

---

## 7. Friend Class

A **friend class** is a class whose member functions are allowed to access the private and protected members of another class.

### Example

```cpp
#include <iostream>
using namespace std;

class A {
private:
    int num = 50;

    friend class B;
};

class B {
public:
    void display(A obj) {
        cout << "Number: " << obj.num << endl;
    }
};

int main() {
    A a;
    B b;

    b.display(a);

    return 0;
}
```

**Output:**
```text
Number: 50
```

**Important:** Friendship is not automatically mutual, inherited, or transitive.

## 8. Lab Work – Printer Hierarchy

### Problem Statement

Design a hierarchy of computer printers. Use multiple inheritance in your hierarchy. Also use friend functions and classes in your program.

### Suggested Class Design

- `Printer` – Base class containing printer details.
- `Scanner` – Base class containing scanning functionality.
- `AllInOnePrinter` – Derived class inheriting from both `Printer` and `Scanner`.
- `PrinterManager` – Friend class that can access private printer details.

### Class Diagram

<pre>
       Printer        Scanner
           \          /
            \        /
          AllInOnePrinter
                  |
            PrinterManager
             (Friend Class)
</pre>

### Implementation

```cpp
#include <iostream>
#include <string>
using namespace std;

class PrinterManager;

class Printer {
private:
    string brand;
    int pagesPrinted;

public:
    Printer(string b, int p)
        : brand(b), pagesPrinted(p) {}

    void printDocument() {
        cout << "Printing document..." << endl;
    }

    friend class PrinterManager;
    friend void showPrinterDetails(Printer);
};

class Scanner {
public:
    void scanDocument() {
        cout << "Scanning document..." << endl;
    }
};

class AllInOnePrinter : public Printer, public Scanner {
public:
    AllInOnePrinter(string b, int p)
        : Printer(b, p) {}

    void displayFunctions() {
        printDocument();
        scanDocument();
    }
};

class PrinterManager {
public:
    void displayDetails(Printer p) {
        cout << "Printer Brand: " << p.brand << endl;
        cout << "Pages Printed: " << p.pagesPrinted << endl;
    }
};

void showPrinterDetails(Printer p) {
    cout << "Brand: " << p.brand << endl;
    cout << "Total Pages: " << p.pagesPrinted << endl;
}

int main() {
    AllInOnePrinter p("HP", 500);

    p.displayFunctions();

    PrinterManager manager;
    manager.displayDetails(p);

    showPrinterDetails(p);

    return 0;
}
```

**Output:**
```text
Printing document...
Scanning document...
Printer Brand: HP
Pages Printed: 500
Brand: HP
Total Pages: 500
```

### Concepts Used in Lab

| Concept | Implementation |
|---|---|
| Multiple Inheritance | `AllInOnePrinter` inherits from `Printer` and `Scanner` |
| Friend Class | `PrinterManager` accesses private printer details |
| Friend Function | `showPrinterDetails()` accesses private members |
| Constructor | Initializes printer brand and page count |
| Encapsulation | Printer details are private |
