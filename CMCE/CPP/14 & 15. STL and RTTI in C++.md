# PART 1: TEMPLATES IN C++

## 1. Introduction to Templates

**Templates** are a feature of C++ that allow us to write generic programs that work with different data types without writing separate code for each type.

Templates support **generic programming** and improve code reusability.

### Why Use Templates?

- Code reusability.
- Avoids writing duplicate functions and classes.
- Supports multiple data types.
- Provides compile-time type checking.
- Makes programs more flexible.

### Types of Templates

| Type | Description |
|---|---|
| Function Template | Creates a generic function |
| Class Template | Creates a generic class |

---

## 2. Function Templates

A **function template** allows us to create a single function that works with different data types.

### Syntax

```cpp
template <typename T>
return_type function_name(T parameter) {
    // Function body
}
```

`typename` and `class` can both be used to declare a type parameter.

### Example: Generic Display Function

```cpp
#include <iostream>
using namespace std;

template <typename T>
void display(T value) {
    cout << "Value: " << value << endl;
}

int main() {
    display(100);
    display(10.5);
    display('A');
    display("Hello C++");

    return 0;
}
```

**Output:**

```text
Value: 100
Value: 10.5
Value: A
Value: Hello C++
```

### Example: Function Template for Addition

```cpp
#include <iostream>
using namespace std;

template <typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    cout << add(10, 20) << endl;
    cout << add(10.5, 20.5) << endl;

    return 0;
}
```

**Output:**

```text
30
31
```

### Function Template with Multiple Parameters

```cpp
#include <iostream>
using namespace std;

template <typename T1, typename T2>
void display(T1 a, T2 b) {
    cout << a << " " << b << endl;
}

int main() {
    display(100, 10.5);
    display("Anurag", 22);

    return 0;
}
```

**Output:**

```text
100 10.5
Anurag 22
```

### Important Points

- Templates use the `template` keyword.
- `typename` and `class` are interchangeable for declaring type parameters.
- The compiler generates suitable function specializations when required.
- Templates support compile-time generic programming.

---

## 3. Class Templates

A **class template** allows us to create a generic class that can work with different data types.

### Syntax

```cpp
template <typename T>
class ClassName {
    T variable;

public:
    // Member functions
};
```

### Example: Generic Box Class

```cpp
#include <iostream>
using namespace std;

template <typename T>
class Box {
private:
    T value;

public:
    Box(T v) {
        value = v;
    }

    void display() {
        cout << "Value: " << value << endl;
    }
};

int main() {
    Box<int> b1(100);
    Box<double> b2(10.5);
    Box<string> b3("Hello C++");

    b1.display();
    b2.display();
    b3.display();

    return 0;
}
```

**Output:**

```text
Value: 100
Value: 10.5
Value: Hello C++
```

### Example: Class Template with Two Parameters

```cpp
#include <iostream>
using namespace std;

template <typename T1, typename T2>
class Student {
private:
    T1 rollNo;
    T2 marks;

public:
    Student(T1 r, T2 m) : rollNo(r), marks(m) {}

    void display() {
        cout << "Roll No: " << rollNo << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main() {
    Student<int, float> s1(101, 85.5);

    s1.display();

    return 0;
}
```

**Output:**

```text
Roll No: 101
Marks: 85.5
```

### Function Template vs Class Template

| Function Template | Class Template |
|---|---|
| Creates generic functions | Creates generic classes |
| Used for reusable operations | Used for reusable data structures and objects |
| Type can often be deduced from function arguments | Class template arguments are generally specified when creating an object |
| Declared using `template` | Declared using `template` |

# PART 2: STANDARD TEMPLATE LIBRARY (STL)

## 4. Introduction to C++ Standard Template Library

**STL (Standard Template Library)** is a collection of generic classes and functions provided by the C++ Standard Library.

It provides ready-to-use data structures and algorithms.

### Main Components of STL

| Component | Description |
|---|---|
| Containers | Store collections of data |
| Algorithms | Perform operations such as sorting and searching |
| Iterators | Access and traverse container elements |
| Function Objects | Objects that can be called like functions |
| Allocators | Manage memory allocation for containers |

### STL Structure

```text
              C++ STL
                 |
      -------------------------
      |           |           |
  Containers  Algorithms  Iterators
      |
  -------------------------------
  |       |       |       |
Vector  Stack   Queue    Map
```

### Advantages of STL

- Ready-made data structures.
- Code reusability.
- Efficient and optimized operations.
- Reduces development time.
- Supports generic programming.

## 5. Vector in C++

A **vector** is a dynamic array that can automatically grow or shrink in size.

It is available through the `<vector>` header.

### Declaration

```cpp
vector<int> v;
```

### Common Vector Operations

| Operation | Description |
|---|---|
| `push_back()` | Adds an element at the end |
| `pop_back()` | Removes the last element |
| `size()` | Returns the number of elements |
| `empty()` | Checks whether the vector is empty |
| `front()` | Returns the first element |
| `back()` | Returns the last element |
| `at()` | Accesses an element with bounds checking |
| `clear()` | Removes all elements |
| `begin()` | Returns an iterator to the first element |
| `end()` | Returns an iterator past the last element |

### Example

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;

    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    cout << "Vector Elements: ";

    for (int x : v) {
        cout << x << " ";
    }

    cout << endl;

    cout << "Size: " << v.size() << endl;
    cout << "First: " << v.front() << endl;
    cout << "Last: " << v.back() << endl;

    v.pop_back();

    cout << "After pop_back: ";

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

**Output:**

```text
Vector Elements: 10 20 30
Size: 3
First: 10
Last: 30
After pop_back: 10 20
```

### Sorting a Vector

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {40, 10, 30, 20};

    sort(v.begin(), v.end());

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

**Output:**

```text
10 20 30 40
```

## 6. Stack in C++

A **stack** is a linear data structure that follows the **LIFO (Last In, First Out)** principle.

The last element inserted is the first element removed.

It is available through the `<stack>` header.

### Stack Operations

| Operation | Description |
|---|---|
| `push()` | Inserts an element |
| `pop()` | Removes the top element |
| `top()` | Returns the top element |
| `size()` | Returns the number of elements |
| `empty()` | Checks whether the stack is empty |

### Stack Diagram

```text
        TOP
      -------
      | 30  |
      -------
      | 20  |
      -------
      | 10  |
      -------
```

### Example

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << "Top Element: " << s.top() << endl;

    s.pop();

    cout << "After pop: " << s.top() << endl;

    cout << "Stack Size: " << s.size() << endl;

    return 0;
}
```

**Output:**

```text
Top Element: 30
After pop: 20
Stack Size: 2
```

### Real-Life Applications

- Undo and redo operations.
- Browser history.
- Function call stack.
- Expression evaluation.
- Parentheses matching.

## 7. Queue in C++

A **queue** is a linear data structure that follows the **FIFO (First In, First Out)** principle.

The first element inserted is the first element removed.

It is available through the `<queue>` header.

### Queue Operations

| Operation | Description |
|---|---|
| `push()` | Inserts an element at the rear |
| `pop()` | Removes the front element |
| `front()` | Returns the front element |
| `back()` | Returns the last element |
| `size()` | Returns the number of elements |
| `empty()` | Checks whether the queue is empty |

### Queue Diagram

```text
FRONT                         REAR
  |                             |
  v                             v
+-----+-----+-----+-----+-----+
| 10  | 20  | 30  | 40  | 50  |
+-----+-----+-----+-----+-----+
```

### Example

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    q.push(10);
    q.push(20);
    q.push(30);

    cout << "Front: " << q.front() << endl;
    cout << "Back: " << q.back() << endl;

    q.pop();

    cout << "After pop: " << q.front() << endl;
    cout << "Size: " << q.size() << endl;

    return 0;
}
```

**Output:**

```text
Front: 10
Back: 30
After pop: 20
Size: 2
```

### Real-Life Applications

- Ticket booking systems.
- Printer job scheduling.
- CPU task scheduling.
- Customer service systems.
- Message processing.

## 8. Map in C++

A **map** is an associative container that stores data in key-value pairs.

Each key is unique, and elements are maintained in sorted order of keys by default.

It is available through the `<map>` header.

### Syntax

```cpp
map<key_type, value_type> mapName;
```

### Map Operations

| Operation | Description |
|---|---|
| `insert()` | Inserts a key-value pair |
| `emplace()` | Constructs an element in place |
| `at()` | Accesses a value using a key |
| `find()` | Searches for a key |
| `erase()` | Removes an element |
| `count()` | Returns the number of matching keys |
| `size()` | Returns the number of elements |
| `empty()` | Checks whether the map is empty |

### Example

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int, string> students;

    students[101] = "Anurag";
    students[102] = "Rahul";
    students[103] = "Amit";

    cout << "Student Records:" << endl;

    for (auto p : students) {
        cout << p.first << " : " << p.second << endl;
    }

    cout << "Student 101: " << students.at(101) << endl;

    return 0;
}
```

**Output:**

```text
Student Records:
101 : Anurag
102 : Rahul
103 : Amit
Student 101: Anurag
```

### Searching in a Map

```cpp
auto it = students.find(102);

if (it != students.end()) {
    cout << "Found: " << it->second;
} else {
    cout << "Not Found";
}
```

### Important Points

- Keys are unique.
- Values can be duplicated.
- Keys are sorted by default.
- `map` generally provides logarithmic search, insertion and deletion.

## 9. Comparison of STL Containers

| Feature | Vector | Stack | Queue | Map |
|---|---|---|---|---|
| Header | `<vector>` | `<stack>` | `<queue>` | `<map>` |
| Structure | Dynamic array | LIFO | FIFO | Key-value pairs |
| Access | Index-based | Top element | Front and back | Key-based |
| Insertion | At end or position | Top | Rear | By key |
| Removal | By position or end | Top | Front | By key |
| Ordering | Insertion order | LIFO behaviour | FIFO behaviour | Sorted by key |

## 10. Iterators in STL

An **iterator** is an object that allows us to access and traverse elements of a container.

It behaves similarly to a pointer.

### Example

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40};

    vector<int>::iterator it;

    for (it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }

    return 0;
}
```

**Output:**

```text
10 20 30 40
```

### Important Iterator Functions

| Function | Description |
|---|---|
| `begin()` | Iterator to first element |
| `end()` | Iterator past the last element |
| `rbegin()` | Reverse iterator to last element |
| `rend()` | Reverse iterator before first element |

# PART 3: RTTI IN C++

## 11. Introduction to RTTI

**RTTI (Run-Time Type Information)** is a C++ feature that allows a program to identify the actual type of an object during program execution.

It is mainly useful in polymorphic class hierarchies.

### RTTI Features

- Identifies the actual type of an object.
- Supports runtime type checking.
- Helps perform safe downcasting.
- Works with polymorphic class hierarchies.

### Main RTTI Operators

| Operator | Purpose |
|---|---|
| `typeid` | Identifies the type of an expression or object |
| `dynamic_cast` | Performs runtime-checked casting in class hierarchies |

---

## 12. typeid Operator

The `typeid` operator returns a reference to a `std::type_info` object that describes the type of an expression.

It is available through the `<typeinfo>` header.

### Syntax

```cpp
typeid(expression)
```

### Example: Basic Type Identification

```cpp
#include <iostream>
#include <typeinfo>
using namespace std;

int main() {
    int a = 10;
    double b = 20.5;

    cout << typeid(a).name() << endl;
    cout << typeid(b).name() << endl;

    return 0;
}
```

**Possible Output:**

```text
i
d
```

**Note:** The exact output of `type_info::name()` is implementation-dependent. It may display compiler-specific type names.

### Example: RTTI with Inheritance

```cpp
#include <iostream>
#include <typeinfo>
using namespace std;

class Base {
public:
    virtual ~Base() = default;
};

class Derived : public Base {
};

int main() {
    Base* ptr = new Derived();

    cout << typeid(*ptr).name() << endl;

    delete ptr;

    return 0;
}
```

**Output:** The compiler displays the runtime type information for `Derived` (the exact spelling is implementation-dependent).

### Important Points

- `typeid` is defined in `<typeinfo>`.
- For a polymorphic class, `typeid(*basePointer)` identifies the dynamic type.
- For a non-polymorphic expression, `typeid` generally identifies its static type.
- Comparing `type_info` objects using `==` checks whether they represent the same type.

---

## 13. dynamic_cast and RTTI

`dynamic_cast` performs runtime-checked conversions within polymorphic class hierarchies.

It is useful when we have a base class pointer or reference and need to check whether it refers to a particular derived class.

### Example

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Dog is barking" << endl;
    }
};

class Cat : public Animal {
};

int main() {
    Animal* ptr = new Dog();

    Dog* d = dynamic_cast<Dog*>(ptr);

    if (d != nullptr) {
        d->bark();
    }

    delete ptr;

    return 0;
}
```

**Output:**

```text
Dog is barking
```

### Failed dynamic_cast Example

```cpp
Animal* ptr = new Cat();

Dog* d = dynamic_cast<Dog*>(ptr);

if (d == nullptr) {
    cout << "Object is not a Dog" << endl;
}

delete ptr;
```

**Output:**

```text
Object is not a Dog
```

---

## 14. RTTI vs Compile-Time Type Checking

| RTTI | Compile-Time Type Checking |
|---|---|
| Works during program execution | Works during compilation |
| Identifies dynamic types in polymorphic hierarchies | Checks types known at compile time |
| Uses `typeid` and `dynamic_cast` | Uses normal type rules and template checks |
| Useful for runtime type identification | Useful for detecting invalid type usage before execution |
