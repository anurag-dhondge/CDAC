## 1. Introduction to Polymorphism

**Polymorphism** is an important concept of Object-Oriented Programming (OOP) that means **one name, many forms**.

It allows the same function, operator or interface to behave differently depending on the situation.

### Types of Polymorphism

C++ supports two major types of polymorphism:

| Type | Description | Examples |
|---|---|---|
| Compile-Time Polymorphism | Resolved during compilation | Function overloading, operator overloading |
| Runtime Polymorphism | Resolved during program execution | Function overriding using virtual functions |

### Diagram

```text
                  Polymorphism
                       |
              -------------------
              |                 |
         Compile-Time       Runtime
          Polymorphism    Polymorphism
              |                 |
        --------------      Virtual Functions
        |            |
     Function     Operator
    Overloading  Overloading
```

## 2. Function Overloading

**Function overloading** allows multiple functions to have the same name but different parameter lists.

Functions can differ in:
- Number of parameters.
- Type of parameters.
- Order of parameter types.

**Note:** Changing only the return type does not create a valid function overload.

### Example

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
};

int main() {
    Calculator c;

    cout << c.add(10, 20) << endl;
    cout << c.add(10.5, 20.5) << endl;
    cout << c.add(10, 20, 30) << endl;

    return 0;
}
```

**Output:**

```text
30
31
60
```

### Function Overloading Based on Different Parameters

| Function | Description |
|---|---|
| `add(int, int)` | Adds two integers |
| `add(double, double)` | Adds two decimal values |
| `add(int, int, int)` | Adds three integers |

### Advantages

- Improves code readability.
- Allows the same operation for different data types.
- Supports compile-time polymorphism.
- Reduces the need for different function names.

## 3. Operator Overloading

**Operator overloading** allows existing C++ operators to work with user-defined data types such as classes and objects.

For example, the `+` operator normally adds numbers, but we can overload it to add two objects.

### Syntax

```cpp
return_type operator symbol(parameters) {
    // Implementation
}
```

### Example: Overloading `+` Operator

```cpp
#include <iostream>
using namespace std;

class Complex {
private:
    int real, imag;

public:
    Complex(int r = 0, int i = 0) {
        real = r;
        imag = i;
    }

    Complex operator+(const Complex& obj) {
        return Complex(real + obj.real,
                       imag + obj.imag);
    }

    void display() {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex c1(10, 20);
    Complex c2(5, 10);

    Complex c3 = c1 + c2;

    c3.display();

    return 0;
}
```

**Output:**

```text
15 + 30i
```

### Explanation

When we write:

```cpp
Complex c3 = c1 + c2;
```

The compiler interprets it as:

```cpp
Complex c3 = c1.operator+(c2);
```

## 4. Important Operators for Overloading

### 4.1 Assignment Operator `=`

Used to assign one object's data to another object.

```cpp
#include <iostream>
using namespace std;

class Number {
    int value;

public:
    Number(int v = 0) : value(v) {}

    Number& operator=(const Number& obj) {
        if (this != &obj) {
            value = obj.value;
        }
        return *this;
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Number n1(100), n2;

    n2 = n1;
    n2.display();

    return 0;
}
```

**Output:**

```text
100
```

For this simple class, the compiler-generated assignment operator would also work. A custom implementation is useful when managing resources such as dynamically allocated memory.

### 4.2 Equality Operator `==`

Used to compare two objects.

```cpp
#include <iostream>
using namespace std;

class Number {
    int value;

public:
    Number(int v) : value(v) {}

    bool operator==(const Number& obj) const {
        return value == obj.value;
    }
};

int main() {
    Number n1(10), n2(10);

    if (n1 == n2)
        cout << "Equal";
    else
        cout << "Not Equal";

    return 0;
}
```

**Output:**

```text
Equal
```

### 4.3 Increment Operator `++`

The increment operator increases a value by one.

There are two forms:

- Prefix: `++obj`
- Postfix: `obj++`

```cpp
#include <iostream>
using namespace std;

class Number {
    int value;

public:
    Number(int v) : value(v) {}

    Number& operator++() {
        ++value;
        return *this;
    }

    Number operator++(int) {
        Number temp = *this;
        value++;
        return temp;
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Number n(10);

    ++n;
    n.display();

    n++;
    n.display();

    return 0;
}
```

**Output:**

```text
11
12
```

**Remember:**
- Prefix `++` has no dummy parameter.
- Postfix `++` uses an `int` dummy parameter.

### 4.4 Decrement Operator `--`

The decrement operator decreases a value by one.

- Prefix: `--obj`
- Postfix: `obj--`

```cpp
#include <iostream>
using namespace std;

class Number {
    int value;

public:
    Number(int v) : value(v) {}

    Number& operator--() {
        --value;
        return *this;
    }

    Number operator--(int) {
        Number temp = *this;
        value--;
        return temp;
    }

    void display() {
        cout << value << endl;
    }
};

int main() {
    Number n(10);

    --n;
    n.display();

    n--;
    n.display();

    return 0;
}
```

**Output:**

```text
9
8
```

### 4.5 Stream Insertion Operator `<<`

Used to display an object using `cout`.

```cpp
#include <iostream>
using namespace std;

class Student {
    int roll;

public:
    Student(int r) : roll(r) {}

    friend ostream& operator<<(ostream& out,
                               const Student& s) {
        out << "Roll No: " << s.roll;
        return out;
    }
};

int main() {
    Student s(101);

    cout << s;

    return 0;
}
```

**Output:**

```text
Roll No: 101
```

### 4.6 Stream Extraction Operator `>>`

Used to read object data using `cin`.

```cpp
#include <iostream>
using namespace std;

class Student {
    int roll;

public:
    friend istream& operator>>(istream& in, Student& s) {
        in >> s.roll;
        return in;
    }

    friend ostream& operator<<(ostream& out,
                               const Student& s) {
        out << "Roll No: " << s.roll;
        return out;
    }
};

int main() {
    Student s;

    cout << "Enter roll number: ";
    cin >> s;

    cout << s;

    return 0;
}
```

**Sample Output:**

```text
Enter roll number: 101
Roll No: 101
```

### 4.7 Subscript Operator `[]`

Used to access elements of an object like an array.

```cpp
#include <iostream>
using namespace std;

class Array {
    int arr[5] = {10, 20, 30, 40, 50};

public:
    int& operator[](int index) {
        return arr[index];
    }
};

int main() {
    Array a;

    cout << a[0] << endl;

    a[1] = 100;

    cout << a[1] << endl;

    return 0;
}
```

**Output:**

```text
10
100
```

In production code, add bounds checking to prevent invalid array access.

### Operator Overloading Summary

| Operator | Purpose |
|---|---|
| `=` | Assignment |
| `==` | Equality comparison |
| `+` | Addition |
| `++` | Increment |
| `--` | Decrement |
| `<<` | Stream insertion / output |
| `>>` | Stream extraction / input |
| `[]` | Array-style element access |

**Important Rules:**
- At least one operand must be a user-defined type.
- Operator precedence and associativity cannot be changed.
- The number of operands cannot be changed.
- Operators such as `::`, `.`, `.*`, `?:` and `sizeof` cannot be overloaded.
- Operators such as `=`, `[]`, `()` and `->` must be overloaded as member functions.

## 5. Friend Functions

A **friend function** is a non-member function that can access the private and protected members of a class when declared using the `friend` keyword.

Friend functions are useful in operator overloading, especially when the left operand is not an object of the class.

### Example: Friend Function for Addition

```cpp
#include <iostream>
using namespace std;

class Number {
    int value;

public:
    Number(int v) : value(v) {}

    friend Number operator+(const Number&,
                            const Number&);
    
    void display() {
        cout << value << endl;
    }
};

Number operator+(const Number& n1,
                 const Number& n2) {
    return Number(n1.value + n2.value);
}

int main() {
    Number n1(10), n2(20);

    Number n3 = n1 + n2;

    n3.display();

    return 0;
}
```

**Output:**

```text
30
```

### Important Points

- A friend function is not a member function.
- It is declared inside the class using `friend`.
- It can access private and protected members.
- It is called like a normal function.
- Friendship is not inherited, mutual or transitive.

## 6. Constant Member Functions

A **constant member function** is a member function that cannot modify the non-static data members of an object.

It is declared using the `const` keyword after the function parameter list.

### Syntax

```cpp
return_type function_name(parameters) const {
    // Function body
}
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int roll;
    string name;

public:
    Student(int r, string n) {
        roll = r;
        name = n;
    }

    void display() const {
        cout << "Roll: " << roll << endl;
        cout << "Name: " << name << endl;
    }
};

int main() {
    const Student s(101, "Anurag");

    s.display();

    return 0;
}
```

**Output:**

```text
Roll: 101
Name: Anurag
```

### Important Points

- A constant member function cannot modify ordinary non-static data members.
- It can be called using constant as well as non-constant objects.
- Constant member functions are useful for read-only operations.
- A `const` member function cannot call a non-const member function on the same object unless another valid overload exists.

## 7. Lab Work – Date and Time Classes

### Problem Statement

- Print dates in `dd/mm/yyyy` format.

### Suggested Class Design

| Class | Responsibilities |
|---|---|
| `Date` | Store day, month and year |
| `Time` | Store hours, minutes and seconds |
| `DateTime` (optional) | Combine date and time operations |

### 7.1 Date Class – Example

The following example demonstrates overloaded constructors and overloaded input/output functions.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

class Date {
private:
    int day, month, year;

public:
    Date() : day(1), month(1), year(2000) {}

    Date(int d, int m, int y)
        : day(d), month(m), year(y) {}

    void read() {
        cout << "Enter date (dd mm yyyy): ";
        cin >> day >> month >> year;
    }

    void print() const {
        cout << setfill('0')
             << setw(2) << day << "/"
             << setw(2) << month << "/"
             << setw(4) << year
             << setfill(' ') << endl;
    }

    void add(int days) {
        // Simplified demonstration:
        // Adds days without handling month/year boundaries.
        day += days;
    }

    friend bool operator==(const Date&, const Date&);
};

bool operator==(const Date& d1, const Date& d2) {
    return d1.day == d2.day &&
           d1.month == d2.month &&
           d1.year == d2.year;
}

int main() {
    Date d1(7, 11, 2026);

    d1.print();

    Date d2;
    d2.read();
    d2.print();

    return 0;
}
```

**Sample Output:**

```text
07/11/2026
Enter date (dd mm yyyy): 10 11 2026
10/11/2026
```

**Note:** This is a basic demonstration. A complete date arithmetic implementation must validate dates, account for leap years, and correctly handle month and year boundaries. For date subtraction, convert dates to a common day count or use a reliable calendar algorithm.

### 7.2 Time Class – Example

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

class Time {
private:
    int hh, mm, ss;

public:
    Time() : hh(0), mm(0), ss(0) {}

    Time(int h, int m, int s)
        : hh(h), mm(m), ss(s) {}

    void read() {
        cout << "Enter time (hh mm ss): ";
        cin >> hh >> mm >> ss;
    }

    void print() const {
        cout << setfill('0')
             << setw(2) << hh << ":"
             << setw(2) << mm << ":"
             << setw(2) << ss
             << setfill(' ') << endl;
    }

    Time add(const Time& t) const {
        int total = hh * 3600 + mm * 60 + ss;
        total += t.hh * 3600 + t.mm * 60 + t.ss;

        total %= 24 * 3600;

        return Time(total / 3600,
                    (total / 60) % 60,
                    total % 60);
    }

    Time subtract(const Time& t) const {
        int total = hh * 3600 + mm * 60 + ss;
        int other = t.hh * 3600 + t.mm * 60 + t.ss;

        total = (total - other + 24 * 3600) % (24 * 3600);

        return Time(total / 3600,
                    (total / 60) % 60,
                    total % 60);
    }
};

int main() {
    Time t1(10, 30, 45);
    Time t2(2, 15, 20);

    Time t3 = t1.add(t2);
    Time t4 = t1.subtract(t2);

    cout << "Addition: ";
    t3.print();

    cout << "Subtraction: ";
    t4.print();

    return 0;
}
```

**Output:**

```text
Addition: 12:46:05
Subtraction: 08:15:25
```

**Note:** This example treats time as a time of day and wraps results around 24 hours. For elapsed-time calculations, use a total-seconds representation without the 24-hour wrap.

## 11. Important Points for Interviews & Exams

- Polymorphism means one name with multiple forms.
- Function overloading is compile-time polymorphism.
- Operator overloading allows operators to work with user-defined types.
- Return type alone cannot distinguish overloaded functions.
- Prefix and postfix operators have different function signatures.
- Friend functions are useful for binary operator overloading.
- `<<` and `>>` are generally overloaded as non-member functions.
- Constant member functions provide read-only access to objects.
- Not every C++ operator can be overloaded.
