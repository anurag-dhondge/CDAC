# 1. Introduction to Memory Management in C++

**Definition:** Memory management is the process of allocating, using, and deallocating memory during program execution.

C++ allows programmers to manage memory manually as well as automatically.

### Types of Memory Areas

| Memory Area | Description |
|---|---|
| Stack | Stores local variables and function call information. |
| Heap (Free Store) | Used for dynamic memory allocation. |
| Global / Static Memory | Stores global and static variables. |
| Code / Text Segment | Stores the compiled program instructions. |

### Stack Memory

- Memory is managed automatically.
- Local variables are generally stored here.
- Memory is released when the variable goes out of scope.
- Allocation and deallocation are generally fast.

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 20;

    cout << a + b;

    return 0;
}
```

**Output:**
```text
30
```

### Heap Memory

- Used for dynamic memory allocation.
- Memory is allocated during runtime.
- Programmer can control its lifetime using `new` and `delete`.
- Smart pointers can manage dynamic memory automatically.

**Example:**

```cpp
int* ptr = new int(100);

cout << *ptr;

delete ptr;
```

**Output:**
```text
100
```

### Stack vs Heap

| Stack | Heap |
|---|---|
| Automatic memory management. | Dynamic memory management. |
| Generally stores local variables. | Stores dynamically allocated objects. |
| Lifetime is generally tied to scope. | Lifetime is controlled by allocation and ownership. |
| Generally faster allocation. | Allocation involves dynamic memory management. |
| Limited size. | Typically larger available memory. |

### Memory Management Problems

| Problem | Meaning |
|---|---|
| Memory Leak | Allocated memory is not released when no longer needed. |
| Dangling Pointer | Pointer refers to memory that is no longer valid. |
| Wild Pointer | Uninitialized pointer containing an indeterminate address. |
| Double Deletion | Deleting the same dynamically allocated memory more than once. |
| Memory Corruption | Invalid memory access or modification. |

**Simple Meaning:** Memory management controls how memory is allocated, used, and released.

# 2. Pointers in C++

**Definition:** A pointer is a variable that stores the memory address of another variable.

### Why Do We Need Pointers?

- Access memory addresses.
- Modify original variables through functions.
- Work with arrays and strings.
- Allocate memory dynamically.
- Implement data structures such as linked lists and trees.

### Pointer Declaration

**Syntax:**

```cpp
data_type* pointer_name;
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;

    int* ptr = &a;

    cout << "Value: " << a << endl;
    cout << "Address: " << &a << endl;
    cout << "Pointer: " << ptr << endl;
    cout << "Value using pointer: " << *ptr << endl;

    return 0;
}
```

**Output (address will vary):**
```text
Value: 10
Address: Memory Address
Pointer: Memory Address
Value using pointer: 10
```

### Important Pointer Operators

| Operator | Name | Purpose |
|---|---|---|
| `&` | Address-of operator | Returns the address of a variable. |
| `*` | Dereference operator | Accesses the value stored at an address. |
| `nullptr` | Null pointer | Represents a pointer that points to no object or function. |

### Understanding Pointers

```cpp
int a = 10;

int* ptr = &a;
```

- `a` → Stores value 10.
- `&a` → Gives the address of `a`.
- `ptr` → Stores the address of `a`.
- `*ptr` → Accesses the value of `a`.

### Modifying a Variable Using a Pointer

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;

    int* ptr = &a;

    *ptr = 50;

    cout << a;

    return 0;
}
```

**Output:**
```text
50
```

**Simple Meaning:** A pointer stores the address of another variable and allows us to access its value.

# 3. Arrays Using Pointers

**Definition:** An array can be accessed using pointers because its elements are stored in contiguous memory locations.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    int* ptr = arr;

    for (int i = 0; i < 5; i++) {
        cout << *(ptr + i) << endl;
    }

    return 0;
}
```

**Output:**
```text
10
20
30
40
50
```

### Understanding Array and Pointer Relationship

For an array:

```cpp
int arr[3] = {10, 20, 30};
```

| Expression | Meaning |
|---|---|
| `arr` | Address of the first element in most expressions. |
| `&arr[0]` | Address of the first element. |
| `*arr` | First element. |
| `*(arr + 1)` | Second element. |
| `*(arr + 2)` | Third element. |

### Pointer Arithmetic

```cpp
int arr[3] = {10, 20, 30};

int* ptr = arr;

cout << *ptr << endl;

ptr++;

cout << *ptr << endl;
```

**Output:**
```text
10
20
```

**Important:** Pointer arithmetic moves according to the size of the pointed-to data type, not simply one byte.

### Array of Pointers

**Definition:** An array of pointers is an array in which each element stores the address of another variable or object.

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 20, c = 30;

    int* ptr[3] = {&a, &b, &c};

    for (int i = 0; i < 3; i++) {
        cout << *ptr[i] << endl;
    }

    return 0;
}
```

**Output:**
```text
10
20
30
```

**Simple Meaning:** Pointers allow us to access array elements using memory addresses.

# 4. Enumeration (enum)

**Definition:** Enumeration is a user-defined data type that consists of a set of named integral constants.

It makes programs more readable by assigning meaningful names to fixed values.

### 4.1 Traditional enum

**Syntax:**

```cpp
enum enum_name {
    value1,
    value2,
    value3
};
```

**Example:**

```cpp
#include <iostream>
using namespace std;

enum Day {
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY
};

int main() {
    Day today = WEDNESDAY;

    cout << today;

    return 0;
}
```

**Output:**
```text
2
```

**Explanation:**

By default, enumeration values start from 0.

| Enum Value | Integer Value |
|---|---:|
| MONDAY | 0 |
| TUESDAY | 1 |
| WEDNESDAY | 2 |
| THURSDAY | 3 |
| FRIDAY | 4 |

### 4.2 enum class (Scoped Enumeration)

C++11 introduced `enum class`, which provides strongly typed and scoped enumerations.

**Example:**

```cpp
#include <iostream>
using namespace std;

enum class Course {
    CPP,
    JAVA,
    PYTHON
};

int main() {
    Course c = Course::CPP;

    if (c == Course::CPP) {
        cout << "C++ Course";
    }

    return 0;
}
```

**Output:**
```text
C++ Course
```

### Difference Between enum and enum class

| enum | enum class |
|---|---|
| Traditional enumeration. | Scoped enumeration. |
| Enumerators can enter the surrounding scope. | Enumerators remain inside the enum scope. |
| Implicit conversion to integer is allowed. | Explicit conversion is required. |
| Less type-safe. | More type-safe. |

**Simple Meaning:** Enumeration allows us to define a group of named constant values.

# 5. Typedef & Type Aliases

**Definition:** `typedef` and `using` allow us to create alternative names for existing data types.

They make complex declarations easier to understand.

### 5.1 typedef

**Syntax:**

```cpp
typedef existing_type new_name;
```

**Example:**

```cpp
#include <iostream>
using namespace std;

typedef unsigned int uint;

int main() {
    uint age = 22;

    cout << age;

    return 0;
}
```

**Output:**
```text
22
```

### 5.2 Type Alias using

C++11 introduced the `using` keyword for creating type aliases.

**Syntax:**

```cpp
using new_name = existing_type;
```

**Example:**

```cpp
#include <iostream>
using namespace std;

using Marks = int;

int main() {
    Marks score = 90;

    cout << score;

    return 0;
}
```

**Output:**
```text
90
```

### Difference Between typedef and using

| typedef | using |
|---|---|
| Older syntax. | Modern C++ syntax. |
| Creates an alternative type name. | Creates an alternative type name. |
| Less convenient for templates. | Supports alias templates. |
| `typedef int Number;` | `using Number = int;` |

### Alias Template Example

```cpp
#include <iostream>
#include <vector>
using namespace std;

template<typename T>
using List = vector<T>;

int main() {
    List<int> numbers = {10, 20, 30};

    for (int n : numbers) {
        cout << n << " ";
    }

    return 0;
}
```

**Output:**
```text
10 20 30
```

**Simple Meaning:** Creates another name for an existing data type.

# 6. Using new Operator

**Definition:** The `new` operator dynamically allocates memory at runtime and returns a pointer to the allocated object.

### Syntax

```cpp
data_type* pointer = new data_type;
```

### Example – Dynamic Memory Allocation

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int;

    *ptr = 100;

    cout << *ptr;

    delete ptr;

    return 0;
}
```

**Output:**
```text
100
```

### Dynamic Initialization

```cpp
int* ptr = new int(50);
```

Here, memory is allocated dynamically and initialized with 50.

### Dynamic Array Allocation

```cpp
#include <iostream>
using namespace std;

int main() {
    int size = 5;

    int* arr = new int[size];

    for (int i = 0; i < size; i++) {
        arr[i] = (i + 1) * 10;
    }

    for (int i = 0; i < size; i++) {
        cout << arr[i] << endl;
    }

    delete[] arr;

    return 0;
}
```

**Output:**
```text
10
20
30
40
50
```

### Important Points

- `new` allocates memory dynamically.
- Returns the address of allocated memory.
- Throws `std::bad_alloc` if allocation fails by default.
- Use `delete` for a single dynamically allocated object.
- Use `delete[]` for dynamically allocated arrays.

**Simple Meaning:** The `new` operator allocates memory dynamically during program execution.

# 7. Pointers to Objects (Class Pointer)

**Definition:** A class pointer is a pointer that stores the memory address of an object of a class.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;

    void display() {
        cout << "Roll Number: " << roll;
    }
};

int main() {
    Student s;

    s.roll = 101;

    Student* ptr = &s;

    ptr->display();

    return 0;
}
```

**Output:**
```text
Roll Number: 101
```

### Understanding the Arrow Operator (`->`)

The arrow operator is used to access members of an object through a pointer.

```cpp
ptr->display();
```

It is equivalent to:

```cpp
(*ptr).display();
```

### Dynamic Object Creation

```cpp
Student* ptr = new Student();

ptr->roll = 101;

ptr->display();

delete ptr;
```

**Simple Meaning:** A class pointer stores the address of an object and accesses its members.

# 8. this Pointer

**Definition:** The `this` pointer is an implicit pointer available inside non-static member functions of a class. It points to the current object.

### Why Do We Need this Pointer?

- To access current object's members.
- To differentiate between class data members and function parameters.
- To return the current object.
- To support method chaining.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;

    void setRoll(int roll) {
        this->roll = roll;
    }

    void display() {
        cout << "Roll Number: " << this->roll;
    }
};

int main() {
    Student s;

    s.setRoll(101);
    s.display();

    return 0;
}
```

**Output:**
```text
Roll Number: 101
```

### Understanding this->

```cpp
this->roll = roll;
```

- `this->roll` → Class data member.
- `roll` → Function parameter.

### Important Points

- `this` is available in non-static member functions.
- It refers to the current object.
- It cannot be used inside static member functions.
- It is an implicit pointer.

**Simple Meaning:** The `this` pointer refers to the current object of a class.

# 9. Smart Pointers in C++

**Definition:** Smart pointers are objects that manage dynamically allocated memory automatically using ownership rules.

They are available through the `<memory>` header file.

### Why Do We Need Smart Pointers?

With raw pointers, programmers must manually manage memory using `new` and `delete`.

Smart pointers help prevent:

- Memory leaks.
- Accidental ownership problems.
- Unnecessary manual memory deallocation.
- Many common dangling-pointer issues.

### Types of Smart Pointers

1. `unique_ptr`
2. `shared_ptr`
3. `weak_ptr`

---

## 9.1 unique_ptr

**Definition:** `unique_ptr` provides exclusive ownership of a dynamically allocated object.

Only one `unique_ptr` can own the object at a time.

### Example

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    unique_ptr<int> ptr = make_unique<int>(100);

    cout << *ptr;

    return 0;
}
```

**Output:**
```text
100
```

### Important Points

- Provides exclusive ownership.
- Cannot be copied.
- Can be moved using `std::move()`.
- Automatically releases memory when ownership ends.

**Simple Meaning:** One smart pointer owns an object at a time.

---

## 9.2 shared_ptr

**Definition:** `shared_ptr` allows multiple smart pointers to share ownership of the same dynamically allocated object.

The object is destroyed when the last owning `shared_ptr` is destroyed or reset.

### Example

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    shared_ptr<int> ptr1 = make_shared<int>(100);

    shared_ptr<int> ptr2 = ptr1;

    cout << "Value: " << *ptr1 << endl;

    cout << "Reference Count: "
         << ptr1.use_count();

    return 0;
}
```

**Output:**
```text
Value: 100
Reference Count: 2
```

### Important Points

- Multiple pointers can share ownership.
- Maintains a reference count.
- Memory is released when the last owning pointer is destroyed.

**Simple Meaning:** Multiple smart pointers can own the same object.

---

## 9.3 weak_ptr

**Definition:** `weak_ptr` provides a non-owning reference to an object managed by `shared_ptr`.

It does not increase the shared ownership reference count.

### Example

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    shared_ptr<int> ptr =
        make_shared<int>(100);

    weak_ptr<int> wptr = ptr;

    if (auto temp = wptr.lock()) {
        cout << *temp;
    }

    return 0;
}
```

**Output:**
```text
100
```

### Important Points

- Does not own the object.
- Does not increase the strong reference count.
- Uses `lock()` to obtain a temporary `shared_ptr`.
- Helps prevent circular ownership problems.

**Simple Meaning:** A weak pointer observes an object without owning it.

---

## 9.4 Difference Between Smart Pointers

| Feature | unique_ptr | shared_ptr | weak_ptr |
|---|---|---|---|
| Ownership | Exclusive | Shared | Non-owning |
| Multiple owners | No | Yes | Does not own |
| Reference count | No shared ownership count | Yes | Does not increase strong count |
| Copying | Not allowed | Allowed | Allowed |
| Memory management | Automatic | Automatic | Observes shared object |
| Main use | Single ownership | Shared ownership | Avoid circular ownership |

### Comparison Example

```cpp
unique_ptr<int> p1 = make_unique<int>(10);

shared_ptr<int> p2 = make_shared<int>(20);

weak_ptr<int> p3 = p2;
```

**Remember:**

- `unique_ptr` → One owner.
- `shared_ptr` → Multiple owners.
- `weak_ptr` → Non-owning observer.

# 10. Memory Deallocation Using delete Operator

**Definition:** The `delete` operator releases memory that was dynamically allocated using `new`.

### 10.1 delete – Single Object

```cpp
#include <iostream>
using namespace std;

int main() {
    int* ptr = new int(100);

    cout << *ptr << endl;

    delete ptr;

    ptr = nullptr;

    return 0;
}
```

**Output:**
```text
100
```

### 10.2 delete[] – Dynamic Array

```cpp
#include <iostream>
using namespace std;

int main() {
    int* arr = new int[3]{10, 20, 30};

    for (int i = 0; i < 3; i++) {
        cout << arr[i] << " ";
    }

    delete[] arr;

    arr = nullptr;

    return 0;
}
```

**Output:**
```text
10 20 30
```

### Difference Between delete and delete[]

| delete | delete[] |
|---|---|
| Releases a single dynamically allocated object. | Releases a dynamically allocated array. |
| Used with `new`. | Used with `new[]`. |
| Calls the object's destructor once. | Calls destructors for all array elements. |

### Important Memory Management Rules

1. Use `new` with `delete`.
2. Use `new[]` with `delete[]`.
3. Do not delete the same memory twice.
4. Avoid accessing memory after deleting it.
5. Set raw pointers to `nullptr` after deletion when appropriate.
6. Prefer smart pointers for automatic memory management.

**Simple Meaning:** The delete operator releases dynamically allocated memory.

## 3. String Operations Using Pointers

Using pointers, write your own functions for the following operations:

### A. String Comparison

**Objective:** Compare two strings character by character.

```cpp
#include <iostream>
using namespace std;

int compareStrings(const char* s1, const char* s2) {
    while (*s1 && *s2 && *s1 == *s2) {
        s1++;
        s2++;
    }

    return static_cast<unsigned char>(*s1) -
           static_cast<unsigned char>(*s2);
}

int main() {
    cout << compareStrings("Hello", "Hello");

    return 0;
}
```

**Output:**
```text
0
```

**Remember:**
- `0` → Strings are equal.
- Negative value → First string is smaller.
- Positive value → First string is greater.

### B. String Concatenation

**Objective:** Join two strings into a single string.

```cpp
#include <iostream>
using namespace std;

bool concatenateStrings(char* dest,
                        const char* src,
                        size_t capacity) {
    size_t i = 0;

    while (i < capacity && dest[i] != '\0') {
        i++;
    }

    if (i == capacity) {
        return false;
    }

    while (*src != '\0') {
        if (i + 1 >= capacity) {
            return false;
        }

        dest[i++] = *src++;
    }

    dest[i] = '\0';

    return true;
}

int main() {
    char str1[30] = "Hello ";
    char str2[] = "Anurag";

    if (concatenateStrings(str1, str2, sizeof(str1))) {
        cout << str1;
    }

    return 0;
}
```

**Output:**
```text
Hello Anurag
```

### C. String Copy

**Objective:** Copy one string into another string.

```cpp
#include <iostream>
using namespace std;

bool copyString(char* dest,
                const char* src,
                size_t capacity) {
    size_t i = 0;

    while (src[i] != '\0') {
        if (i + 1 >= capacity) {
            return false;
        }

        dest[i] = src[i];
        i++;
    }

    if (capacity == 0) {
        return false;
    }

    dest[i] = '\0';

    return true;
}

int main() {
    char source[] = "Anurag";
    char destination[20];

    if (copyString(destination, source,
                   sizeof(destination))) {
        cout << destination;
    }

    return 0;
}
```

**Output:**
```text
Anurag
```

### D. String Length

**Objective:** Calculate the length of a string without using the built-in `strlen()` function.

```cpp
#include <iostream>
using namespace std;

int stringLength(const char* str) {
    int count = 0;

    while (*str != '\0') {
        count++;
        str++;
    }

    return count;
}

int main() {
    char name[] = "Anurag";

    cout << "Length = " << stringLength(name);

    return 0;
}
```

**Output:**
```text
Length = 6
```

**Important:** These string functions use null-terminated C-style strings. The destination arrays must have sufficient capacity, and source and destination buffers should not overlap.
