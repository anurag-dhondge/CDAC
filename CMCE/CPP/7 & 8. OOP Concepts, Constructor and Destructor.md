# 1. Object-Oriented Programming (OOP) Concepts

**Definition:** Object-Oriented Programming is a programming approach that organizes code around objects and classes rather than only functions and procedures.

OOP helps us develop reusable, modular, secure, and maintainable applications.

### Important OOP Concepts

1. Class
2. Object
3. Encapsulation
4. Abstraction
5. Inheritance
6. Polymorphism

### Four Pillars of OOP

| Pillar | Definition | Simple Meaning |
|---|---|---|
| Encapsulation | Wrapping data and methods into a single unit. | Binding data and functions together. |
| Abstraction | Hiding implementation details and showing essential functionality. | Showing only necessary information. |
| Inheritance | Acquiring properties and methods from another class. | Reusing existing class functionality. |
| Polymorphism | One interface can have multiple forms of behaviour. | One name, multiple behaviours. |

### Example – Real-Life Understanding

Consider a Student Management System.

- **Encapsulation:** Student data and methods are placed inside a Student class.
- **Abstraction:** Users can call `display()` without knowing its internal implementation.
- **Inheritance:** A GraduateStudent class can inherit from Student.
- **Polymorphism:** Different student types can implement their own `display()` behaviour.

**Simple Meaning:** OOP organizes programs using classes and objects and provides code reusability, data protection, and flexibility.

# 2. Classes and Objects

## 2.1 Class

**Definition:** A class is a user-defined data type that acts as a blueprint for creating objects.

It contains data members and member functions.

### Syntax

```cpp
class ClassName {
    // Data members
    // Member functions
};
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;
    string name;

    void display() {
        cout << "Roll: " << roll << endl;
        cout << "Name: " << name << endl;
    }
};

int main() {
    Student s1;

    s1.roll = 101;
    s1.name = "Anurag";

    s1.display();

    return 0;
}
```

**Output:**

```text
Roll: 101
Name: Anurag
```

## 2.2 Object

**Definition:** An object is an instance of a class that has its own state and can use the behaviour defined by the class.

### Example

```cpp
Student s1;
Student s2;
Student s3;
```

Here:
- `Student` → Class.
- `s1`, `s2`, `s3` → Objects.

### Class vs Object

| Class | Object |
|---|---|
| Blueprint of an object. | Instance of a class. |
| Logical definition. | Runtime entity. |
| Defines data members and methods. | Holds its own non-static data. |
| Example: Student | Example: s1, s2 |

**Simple Meaning:** A class is a blueprint, and an object is an instance created from that blueprint.

# 3. Access Specifiers

**Definition:** Access specifiers define the visibility and accessibility of class members.

C++ provides three main access specifiers:

1. `public`
2. `private`
3. `protected`

### 3.1 public

Members declared as public can be accessed from anywhere they are otherwise accessible.

```cpp
class Student {
public:
    int roll = 101;
};
```

### 3.2 private

Members declared as private can only be accessed directly from member functions and friends of that class.

```cpp
class Student {
private:
    int marks = 90;

public:
    void display() {
        cout << marks;
    }
};
```

### 3.3 protected

Protected members can be accessed inside the class, its friends, and derived classes.

```cpp
class Student {
protected:
    int roll = 101;
};

class Result : public Student {
public:
    void display() {
        cout << roll;
    }
};
```

### Comparison

| Access Specifier | Same Class | Derived Class | Outside Class |
|---|---|---|---|
| public | Yes | Yes | Yes |
| private | Yes | No direct access | No |
| protected | Yes | Yes | No |

### Important Point

The default access specifier of a `class` is `private`, whereas the default access specifier of a `struct` is `public`.

**Simple Meaning:** Access specifiers control who can access class members.

# 4. Inheritance

**Definition:** Inheritance is an OOP feature that allows one class to acquire the properties and behaviour of another class.

- Base Class → Parent Class.
- Derived Class → Child Class.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    void study() {
        cout << "Student is studying" << endl;
    }
};

class GraduateStudent : public Student {
public:
    void project() {
        cout << "Working on final year project";
    }
};

int main() {
    GraduateStudent s;

    s.study();
    s.project();

    return 0;
}
```

**Output:**

```text
Student is studying
Working on final year project
```

### Types of Inheritance

| Type | Description |
|---|---|
| Single Inheritance | One derived class inherits from one base class. |
| Multiple Inheritance | One derived class inherits from multiple base classes. |
| Multilevel Inheritance | A class inherits from another derived class. |
| Hierarchical Inheritance | Multiple derived classes inherit from one base class. |
| Hybrid Inheritance | Combination of two or more inheritance types. |

**Simple Meaning:** Inheritance allows one class to reuse the properties and methods of another class.

*Note: Inheritance is covered in greater detail in Session 9.*

# 5. Polymorphism

**Definition:** Polymorphism means one name or interface can represent multiple forms of behaviour.

### Types of Polymorphism

1. Compile-Time Polymorphism
2. Runtime Polymorphism

### 5.1 Compile-Time Polymorphism

Achieved through:
- Function Overloading.
- Operator Overloading.

**Example – Function Overloading**

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
};

int main() {
    Calculator c;

    cout << c.add(10, 20) << endl;
    cout << c.add(10, 20, 30);

    return 0;
}
```

**Output:**

```text
30
60
```

### 5.2 Runtime Polymorphism

Achieved through virtual functions and function overriding.

**Example:**

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    virtual void sound() {
        cout << "Animal sound";
    }

    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void sound() override {
        cout << "Dog barks";
    }
};

int main() {
    Dog d;

    Animal* ptr = &d;

    ptr->sound();

    return 0;
}
```

**Output:**

```text
Dog barks
```

**Simple Meaning:** Polymorphism allows the same interface to perform different operations.

*Note: Polymorphism is covered in greater detail in Session 10.*

# 6. Namespaces

**Definition:** A namespace is a declarative region that provides a scope to identifiers such as variables, functions, and classes.

It helps prevent naming conflicts in large programs.

### Syntax

```cpp
namespace namespace_name {
    // Variables
    // Functions
    // Classes
}
```

### Example

```cpp
#include <iostream>
using namespace std;

namespace First {
    int value = 10;
}

namespace Second {
    int value = 20;
}

int main() {
    cout << First::value << endl;
    cout << Second::value << endl;

    return 0;
}
```

**Output:**

```text
10
20
```

### Scope Resolution Operator (`::`)

The `::` operator is used to access members of a namespace.

```cpp
First::value;
Second::value;
```

### Using Namespace

```cpp
using namespace First;
```

This allows identifiers from `First` to be used without writing the namespace name, provided there are no naming conflicts.

**Simple Meaning:** A namespace groups related identifiers and helps avoid naming conflicts.

# 7. Constructors and Destructors

## 7.1 Constructor

**Definition:** A constructor is a special member function of a class that is automatically called when an object is created.

### Important Characteristics

- Constructor name is the same as the class name.
- It has no return type.
- It is automatically called when an object is created.
- It can be overloaded.
- It is generally used to initialize objects.

### Syntax

```cpp
class Student {
public:
    Student() {
        // Constructor body
    }
};
```

### Example – Default Constructor

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    Student() {
        cout << "Constructor Called";
    }
};

int main() {
    Student s1;

    return 0;
}
```

**Output:**

```text
Constructor Called
```

**Simple Meaning:** A constructor initializes an object when it is created.

---

## 7.2 Destructor

**Definition:** A destructor is a special member function that is automatically called when an object is destroyed.

### Important Characteristics

- Destructor name is the class name preceded by `~`.
- It has no return type.
- It does not accept parameters.
- A class can have only one destructor.
- It is used for cleanup operations.

### Syntax

```cpp
class Student {
public:
    ~Student() {
        // Cleanup code
    }
};
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    Student() {
        cout << "Constructor Called" << endl;
    }

    ~Student() {
        cout << "Destructor Called" << endl;
    }
};

int main() {
    Student s1;

    return 0;
}
```

**Output:**

```text
Constructor Called
Destructor Called
```

**Simple Meaning:** A destructor performs cleanup when an object is destroyed.

---

## 7.3 Constructor vs Destructor

| Constructor | Destructor |
|---|---|
| Initializes an object. | Cleans up an object. |
| Same name as class. | Same name with `~` prefix. |
| Called when object is created. | Called when object is destroyed. |
| Can accept parameters. | Cannot accept parameters. |
| Can be overloaded. | Cannot be overloaded. |
| Multiple constructors are allowed. | Only one destructor per class. |

# 8. Parameterized Constructors

**Definition:** A parameterized constructor is a constructor that accepts arguments to initialize an object's data members.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;
    string name;

    Student(int r, string n) {
        roll = r;
        name = n;
    }

    void display() {
        cout << roll << " " << name;
    }
};

int main() {
    Student s1(101, "Anurag");

    s1.display();

    return 0;
}
```

**Output:**

```text
101 Anurag
```

### Constructor Initialization List

C++ also allows data members to be initialized using an initializer list.

```cpp
class Student {
public:
    int roll;
    string name;

    Student(int r, string n)
        : roll(r), name(n) {
    }
};
```

**Simple Meaning:** A parameterized constructor initializes objects using values passed during object creation.

---

# 9. Multiple Constructors in a Class

**Definition:** Defining multiple constructors with different parameter lists inside the same class is called constructor overloading.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;
    string name;

    Student() {
        roll = 0;
        name = "Unknown";
    }

    Student(int r) {
        roll = r;
        name = "Unknown";
    }

    Student(int r, string n) {
        roll = r;
        name = n;
    }

    void display() {
        cout << roll << " " << name << endl;
    }
};

int main() {
    Student s1;
    Student s2(101);
    Student s3(102, "Anurag");

    s1.display();
    s2.display();
    s3.display();

    return 0;
}
```

**Output:**

```text
0 Unknown
101 Unknown
102 Anurag
```

### Important Point

The compiler selects the appropriate constructor based on the arguments supplied during object creation.

**Simple Meaning:** A class can have multiple constructors to initialize objects in different ways.

# 10. Dynamic Initialization of Objects

**Definition:** Dynamic initialization of objects means initializing an object's data members using values determined at runtime.

These values may come from user input, calculations, or other runtime operations.

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;
    string name;

    Student(int r, string n) {
        roll = r;
        name = n;
    }

    void display() {
        cout << "Roll: " << roll << endl;
        cout << "Name: " << name << endl;
    }
};

int main() {
    int r;
    string n;

    cout << "Enter Roll Number: ";
    cin >> r;

    cout << "Enter Name: ";
    cin >> n;

    Student s(r, n);

    s.display();

    return 0;
}
```

**Sample Output:**

```text
Enter Roll Number: 101
Enter Name: Anurag
Roll: 101
Name: Anurag
```

**Simple Meaning:** Objects are initialized using values available at runtime.

# 11. Copy Constructors

**Definition:** A copy constructor is a special constructor that creates a new object by initializing it from an existing object of the same class.

### Syntax

```cpp
ClassName(const ClassName& obj);
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll;

    Student(int r) {
        roll = r;
    }

    Student(const Student& obj) {
        roll = obj.roll;

        cout << "Copy Constructor Called" << endl;
    }

    void display() {
        cout << "Roll: " << roll << endl;
    }
};

int main() {
    Student s1(101);

    Student s2 = s1;

    s1.display();
    s2.display();

    return 0;
}
```

**Output:**

```text
Copy Constructor Called
Roll: 101
Roll: 101
```

### Important Points

- Copy constructor initializes a new object from an existing object.
- It generally accepts a reference to a constant object.
- It is important when working with objects containing dynamically allocated resources.
- The compiler can generate a default copy constructor if one is not provided.

### Shallow Copy vs Deep Copy

| Shallow Copy | Deep Copy |
|---|---|
| Copies member values directly. | Creates independent copies of dynamically owned resources. |
| Pointer members may point to the same memory. | Pointer members point to separately allocated memory. |
| Can cause ownership and double-deletion problems. | Provides independent ownership. |

**Simple Meaning:** A copy constructor creates a new object using an existing object.

# 12. Move Semantics

**Definition:** Move semantics allow resources owned by one object to be transferred to another object instead of copying the resources.

Move semantics were introduced in C++11.

### Why Do We Need Move Semantics?

Consider an object containing a large dynamically allocated array.

- Copying duplicates the data.
- Moving transfers ownership of the resource.
- Moving can avoid unnecessary expensive copies.

## 12.1 Lvalue

**Definition:** An lvalue is an expression that identifies an object or function and generally has a persistent identity.

### Example

```cpp
int a = 10;

a = 20;
```

Here, `a` is an lvalue because it identifies a specific object in memory.

## 12.2 Rvalue

**Definition:** An rvalue is an expression that is generally used as a temporary value rather than identifying a persistent object.

### Example

```cpp
int a = 10;

int b = a + 20;
```

Here:
- `a` → Lvalue.
- `20` → Prvalue.
- `a + 20` → Prvalue.

### Difference Between Lvalue and Rvalue

| Lvalue | Rvalue |
|---|---|
| Identifies an object or function. | Represents a value or temporary expression. |
| Has an identifiable location. | Generally does not represent a persistent named object. |
| Can usually appear on the left side of assignment. | Cannot generally be assigned to. |
| Example: `a` | Example: `10`, `a + 5` |

---

## 12.3 Move Constructor

**Definition:** A move constructor initializes a new object by transferring resources from another object, usually an rvalue.

### Syntax

```cpp
ClassName(ClassName&& obj);
```

### Example

```cpp
#include <iostream>
#include <utility>
using namespace std;

class Student {
public:
    int* marks;

    Student(int m) {
        marks = new int(m);
    }

    // Move Constructor
    Student(Student&& obj) noexcept {
        marks = obj.marks;

        obj.marks = nullptr;

        cout << "Move Constructor Called" << endl;
    }

    ~Student() {
        delete marks;
    }
};

int main() {
    Student s1(90);

    Student s2 = std::move(s1);

    cout << *s2.marks;

    return 0;
}
```

**Output:**

```text
Move Constructor Called
90
```

### Understanding std::move()

`std::move()` does not itself move resources. It converts an expression into an rvalue reference so that a suitable move operation can be selected.

### Copy Constructor vs Move Constructor

| Copy Constructor | Move Constructor |
|---|---|
| Copies resources. | Transfers resources. |
| Accepts `const ClassName&`. | Usually accepts `ClassName&&`. |
| Can involve expensive copying. | Can avoid expensive copying. |
| Original object remains unchanged. | Original object is generally left in a valid but unspecified state. |

**Simple Meaning:** Move semantics transfer resources instead of unnecessarily copying them.

# 13. Static Members

**Definition:** Static members belong to the class rather than individual objects.

Static data members are shared by all objects of the class.

### Static Data Member

**Example:**

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    static int count;

    Student() {
        count++;
    }
};

int Student::count = 0;

int main() {
    Student s1;
    Student s2;
    Student s3;

    cout << "Total Students: " << Student::count;

    return 0;
}
```

**Output:**

```text
Total Students: 3
```

### Static Member Function

A static member function belongs to the class and can be called without creating an object.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    static int count;

    static void display() {
        cout << count;
    }
};

int Student::count = 10;

int main() {
    Student::display();

    return 0;
}
```

**Output:**

```text
10
```

### Important Points

- Static data members are shared among objects.
- Static member functions can be called using the class name.
- Static member functions do not have a `this` pointer.
- Static member functions cannot directly access non-static members.

**Simple Meaning:** Static members are shared by all objects of a class.

# 14. Constant Members

**Definition:** Constant members are members declared using the `const` keyword whose values cannot be changed after initialization.

### 14.1 Constant Data Members

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    const int roll;

    Student(int r) : roll(r) {
    }

    void display() {
        cout << "Roll: " << roll;
    }
};

int main() {
    Student s1(101);

    s1.display();

    return 0;
}
```

**Output:**

```text
Roll: 101
```

**Important:** A const data member must be initialized using a constructor initialization list.

### 14.2 Constant Member Functions

**Definition:** A constant member function does not modify the object's non-mutable data members.

**Syntax:**

```cpp
return_type function_name() const {
    // Statements
}
```

### Example

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    int roll = 101;

    void display() const {
        cout << "Roll: " << roll;
    }
};

int main() {
    Student s1;

    s1.display();

    return 0;
}
```

**Output:**

```text
Roll: 101
```

### Static vs Constant Members

| Static Members | Constant Members |
|---|---|
| Belong to the class. | Cannot be modified after initialization. |
| Shared among objects. | May belong to individual objects. |
| Declared using `static`. | Declared using `const`. |
| Can maintain shared information. | Help protect data from modification. |

**Simple Meaning:** Constant members protect values from modification.

## 1. Student Management System Using Class and Objects

**Objective:**

Write a Student class and use it in your program.

- Store the data of 10 students.
- Display student records sorted according to roll numbers.
- Display student records sorted according to dates of birth.
- Display student records sorted according to total marks.

### Student Class Requirements

| Data Member | Data Type |
|---|---|
| Roll Number | int |
| Student Name | string |
| Date of Birth | string |
| Total Marks | double |

### Implementation

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <vector>
using namespace std;

class Student {
private:
    int roll;
    string name;
    string dob;  // YYYY-MM-DD format
    double marks;

public:
    // Parameterized Constructor
    Student(int r, string n, string d, double m)
        : roll(r), name(n), dob(d), marks(m) {
        cout << "Constructor called for " << name << endl;
    }

    // Destructor
    ~Student() {
        cout << "Destructor called for " << name << endl;
    }

    int getRoll() const {
        return roll;
    }

    string getName() const {
        return name;
    }

    string getDOB() const {
        return dob;
    }

    double getMarks() const {
        return marks;
    }

    void display() const {
        cout << roll << "\t"
             << name << "\t"
             << dob << "\t"
             << marks << endl;
    }
};

void displayStudents(const vector<Student*>& students) {
    cout << "\nRoll\tName\tDOB\t\tMarks\n";

    for (const Student* s : students) {
        s->display();
    }
}

int main() {

    // Creating 10 Student Objects
    Student students[10] = {
        {105, "Anurag",  "2004-01-30", 90},
        {102, "Rahul",   "2003-05-12", 85},
        {109, "Sushant", "2004-03-20", 95},
        {101, "Amit",    "2003-01-15", 80},
        {107, "Rohit",   "2004-07-10", 88},
        {103, "Sneha",   "2003-09-25", 92},
        {110, "Priya",   "2004-11-05", 78},
        {104, "Akash",   "2003-06-18", 89},
        {106, "Neha",    "2004-02-14", 96},
        {108, "Kiran",   "2003-12-30", 82}
    };

    // Store pointers to student objects
    vector<Student*> list;

    for (int i = 0; i < 10; i++) {
        list.push_back(&students[i]);
    }

    // Original Records
    cout << "\nOriginal Student Records:";
    displayStudents(list);

    // Sort by Roll Number
    sort(list.begin(), list.end(),
        [](Student* a, Student* b) {
            return a->getRoll() < b->getRoll();
        });

    cout << "\nSorted by Roll Number:";
    displayStudents(list);

    // Sort by Date of Birth
    sort(list.begin(), list.end(),
        [](Student* a, Student* b) {
            return a->getDOB() < b->getDOB();
        });

    cout << "\nSorted by Date of Birth:";
    displayStudents(list);

    // Sort by Total Marks (Descending)
    sort(list.begin(), list.end(),
        [](Student* a, Student* b) {
            return a->getMarks() > b->getMarks();
        });

    cout << "\nSorted by Total Marks:";
    displayStudents(list);

    return 0;
}
```

### Understanding the Program

| Concept | Implementation |
|---|---|
| Class | `Student` |
| Objects | 10 Student objects |
| Private Members | roll, name, dob, marks |
| Parameterized Constructor | Initializes student details |
| Destructor | Displays object destruction |
| Encapsulation | Private data and public methods |
| Array of Objects | `Student students[10]` |
| Pointers | `vector<Student*>` |
| Sorting | `sort()` from STL |
| Lambda Expressions | Custom sorting conditions |
| Constant Functions | Getter methods declared using `const` |

**Important:** Dates are stored in `YYYY-MM-DD` format so that lexicographical sorting gives chronological order. The sorting is performed on pointers, so the original student objects are not moved.
