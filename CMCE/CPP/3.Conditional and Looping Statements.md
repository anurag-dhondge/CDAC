# 1. Conditional Statements

**Definition:** Conditional statements are used to execute different blocks of code depending on whether a given condition is true or false.

C++ provides the following conditional statements:

1. `if`
2. `if-else`
3. `else-if`
4. `nested if`
5. `switch`

## 1.1 if Statement

**Definition:** The `if` statement executes a block of code only when the given condition is true.

**Syntax:**

```cpp
if (condition) {
    // Statements
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 22;

    if (age >= 18) {
        cout << "Eligible to vote";
    }

    return 0;
}
```

**Output:**
```text
Eligible to vote
```

**Simple Meaning:** Executes code when the condition is true.

---

## 1.2 if-else Statement

**Definition:** The `if-else` statement executes one block when the condition is true and another block when it is false.

**Syntax:**

```cpp
if (condition) {
    // True block
} else {
    // False block
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 10;

    if (num % 2 == 0) {
        cout << "Even Number";
    } else {
        cout << "Odd Number";
    }

    return 0;
}
```

**Output:**
```text
Even Number
```

**Simple Meaning:** Chooses between two blocks of code.

---

## 1.3 else-if Ladder

**Definition:** An else-if ladder is used to check multiple conditions one by one.

**Syntax:**

```cpp
if (condition1) {
    // Statements
}
else if (condition2) {
    // Statements
}
else if (condition3) {
    // Statements
}
else {
    // Default statements
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks = 85;

    if (marks >= 90) {
        cout << "Grade A+";
    }
    else if (marks >= 75) {
        cout << "Grade A";
    }
    else if (marks >= 60) {
        cout << "Grade B";
    }
    else {
        cout << "Grade C";
    }

    return 0;
}
```

**Output:**
```text
Grade A
```

**Simple Meaning:** Checks multiple conditions in sequence.

---

## 1.4 Nested if Statement

**Definition:** An if statement inside another if statement is called a nested if statement.

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 22;
    bool hasLicense = true;

    if (age >= 18) {
        if (hasLicense) {
            cout << "Eligible to drive";
        }
    }

    return 0;
}
```

**Output:**
```text
Eligible to drive
```

**Simple Meaning:** An if statement inside another if statement.

---

## 1.5 switch Statement

**Definition:** The switch statement is used to select one block of code from multiple alternatives based on an expression's value.

**Syntax:**

```cpp
switch (expression) {
    case value1:
        // Statements
        break;

    case value2:
        // Statements
        break;

    default:
        // Default statements
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice = 2;

    switch (choice) {
        case 1:
            cout << "Monday";
            break;

        case 2:
            cout << "Tuesday";
            break;

        case 3:
            cout << "Wednesday";
            break;

        default:
            cout << "Invalid Choice";
    }

    return 0;
}
```

**Output:**
```text
Tuesday
```

**Simple Meaning:** Selects one option from multiple cases.

# 2. Loops in C++

**Definition:** Loops are used to execute a block of code repeatedly until a specified condition becomes false.

C++ provides three main types of loops:

1. for loop
2. while loop
3. do-while loop

## 2.1 for Loop

**Definition:** A for loop is used when the number of iterations is known or controlled by a loop condition.

**Syntax:**

```cpp
for (initialization; condition; update) {
    // Statements
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << endl;
    }

    return 0;
}
```

**Output:**
```text
1
2
3
4
5
```

**Execution:**

1. Initialization – `int i = 1`
2. Condition – `i <= 5`
3. Statement execution
4. Update – `i++`
5. Repeat until condition becomes false.

**Simple Meaning:** Repeats code using initialization, condition, and update.

---

## 2.2 while Loop

**Definition:** A while loop executes a block of code as long as the given condition is true.

**Syntax:**

```cpp
while (condition) {
    // Statements
}
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    while (i <= 5) {
        cout << i << endl;
        i++;
    }

    return 0;
}
```

**Output:**
```text
1
2
3
4
5
```

**Simple Meaning:** Repeats code while the condition remains true.

---

## 2.3 do-while Loop

**Definition:** A do-while loop executes the code block at least once before checking the condition.

**Syntax:**

```cpp
do {
    // Statements
} while (condition);
```

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;

    do {
        cout << i << endl;
        i++;
    } while (i <= 5);

    return 0;
}
```

**Output:**
```text
1
2
3
4
5
```

**Simple Meaning:** Executes code at least once, then checks the condition.

---

## 2.4 Difference Between for, while and do-while

| for Loop | while Loop | do-while Loop |
|---|---|---|
| Entry-controlled loop | Entry-controlled loop | Exit-controlled loop |
| Initialization, condition, update in one statement | Initialization and update are generally separate | Condition is checked after execution |
| Suitable when iterations are known | Suitable when iterations depend on a condition | Suitable when code must execute at least once |
| May execute zero times | May execute zero times | Executes at least once |

# 3. Jump Statements

**Definition:** Jump statements change the normal flow of program execution.

C++ provides the following jump statements:

1. `break`
2. `continue`
3. `return`

## 3.1 break Statement

**Definition:** The break statement terminates the nearest enclosing loop or switch statement immediately.

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {

        if (i == 5) {
            break;
        }

        cout << i << endl;
    }

    return 0;
}
```

**Output:**
```text
1
2
3
4
```

**Simple Meaning:** Completely exits the loop or switch.

---

## 3.2 continue Statement

**Definition:** The continue statement skips the remaining statements of the current loop iteration and moves to the next iteration.

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {

        if (i == 3) {
            continue;
        }

        cout << i << endl;
    }

    return 0;
}
```

**Output:**
```text
1
2
4
5
```

**Simple Meaning:** Skips the current iteration and continues with the next one.

---

## 3.3 return Statement

**Definition:** The return statement terminates a function and optionally sends a value back to the calling function.

**Example:**

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(10, 20);

    cout << result;

    return 0;
}
```

**Output:**
```text
30
```

**Simple Meaning:** Returns control from a function, optionally with a value.

---

## 3.4 Difference Between break, continue and return

| Statement | Purpose |
|---|---|
| `break` | Terminates the nearest loop or switch. |
| `continue` | Skips the current loop iteration. |
| `return` | Exits the current function. |

# 4. Arrays in C++

**Definition:** An array is a collection of elements of the same data type stored in contiguous memory locations.

### Why Do We Need Arrays?

Suppose we want to store marks of five students.

Without an array:

```cpp
int m1 = 80;
int m2 = 85;
int m3 = 90;
int m4 = 75;
int m5 = 88;
```

Using an array:

```cpp
int marks[5] = {80, 85, 90, 75, 88};
```

**Simple Meaning:** An array stores multiple values of the same data type using a single variable name.

---

# 5. Declaration and Initialization of an Array

## 5.1 Array Declaration

**Syntax:**

```cpp
data_type array_name[size];
```

**Example:**

```cpp
int numbers[5];
```

Here:
- `int` → Data type
- `numbers` → Array name
- `5` → Number of elements

## 5.2 Array Initialization

**Example:**

```cpp
int numbers[5] = {10, 20, 30, 40, 50};
```

### Accessing Array Elements

Array indexing starts from `0`.

| Index | Value |
|:---:|:---:|
| 0 | 10 |
| 1 | 20 |
| 2 | 30 |
| 3 | 40 |
| 4 | 50 |

**Example:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    cout << numbers[0] << endl;
    cout << numbers[2] << endl;

    return 0;
}
```

**Output:**
```text
10
30
```

# 6. One-Dimensional Array (1-D Array)

**Definition:** A one-dimensional array stores elements in a linear sequence and uses one index to access its elements.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[5] = {80, 85, 90, 75, 88};

    for (int i = 0; i < 5; i++) {
        cout << marks[i] << endl;
    }

    return 0;
}
```

**Output:**
```text
80
85
90
75
88
```

### Sum of Array Elements

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum += arr[i];
    }

    cout << "Sum = " << sum;

    return 0;
}
```

**Output:**
```text
Sum = 150
```

**Simple Meaning:** A linear collection of elements accessed using one index.

# 7. Two-Dimensional Array (2-D Array)

**Definition:** A two-dimensional array stores elements in rows and columns, similar to a matrix or table.

### Declaration

```cpp
data_type array_name[rows][columns];
```

### Example

```cpp
int matrix[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};
```

### Visual Representation

| Row / Column | 0 | 1 | 2 |
|---|---:|---:|---:|
| 0 | 10 | 20 | 30 |
| 1 | 40 | 50 | 60 |

### Displaying a 2-D Array

```cpp
#include <iostream>
using namespace std;

int main() {
    int matrix[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << matrix[i][j] << " ";
        }

        cout << endl;
    }

    return 0;
}
```

**Output:**
```text
10 20 30
40 50 60
```

**Simple Meaning:** A collection of elements arranged in rows and columns.

# 8. Command-Line Arguments in C++

**Definition:** Command-line arguments are values passed to a program when it is executed from the command line.

C++ accepts command-line arguments through the `main()` function.

### Syntax

```cpp
int main(int argc, char* argv[]) {
    // Program statements
}
```

### Important Parameters

| Parameter | Meaning |
|---|---|
| `argc` | Argument count – number of command-line arguments, including the program name. |
| `argv` | Argument vector – array of C-style strings containing the arguments. |
| `argv[0]` | Program name or invocation path. |
| `argv[1]` | First user-supplied argument. |
| `argv[2]` | Second user-supplied argument. |

### Example

```cpp
#include <iostream>
using namespace std;

int main(int argc, char* argv[]) {

    cout << "Argument Count: " << argc << endl;

    for (int i = 0; i < argc; i++) {
        cout << "Argument " << i << ": "
             << argv[i] << endl;
    }

    return 0;
}
```

### Compile

```bash
g++ -std=c++17 main.cpp -o main
```

### Execute

```bash
main.exe Anurag 22 Pune
```

**Output (illustrative):**
```text
Argument Count: 4
Argument 0: main.exe
Argument 1: Anurag
Argument 2: 22
Argument 3: Pune
```

**Remember:**
- `argc` counts all arguments, including the program name.
- `argv` stores arguments as strings.
- Convert arguments to numeric types when performing mathematical operations.
