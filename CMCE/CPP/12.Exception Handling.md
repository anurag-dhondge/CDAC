## 1. Introduction to Exception Handling

**Exception handling** is a mechanism in C++ used to handle runtime errors and unexpected situations without abruptly terminating the program.

It helps maintain normal program flow by separating error-handling code from regular application logic.

### Examples of Exceptions

- Division by zero.
- Invalid user input.
- Accessing an invalid array index.
- File opening failure.
- Insufficient memory.
- Invalid operations in a program.

### Why Exception Handling?

- Prevents unexpected program termination when an exception is handled.
- Separates normal code from error-handling code.
- Improves program reliability.
- Helps identify and manage errors.
- Supports propagation of errors between functions.

---

## 2. Exception Handling Keywords

C++ provides three main keywords for exception handling.

| Keyword | Description |
|---|---|
| `try` | Defines a block of code where an exception may occur. |
| `throw` | Throws an exception when an error occurs. |
| `catch` | Handles an exception thrown from a matching try block. |

### Basic Syntax

```cpp
try {
    // Code that may generate an exception
    throw exception;
}
catch (type variable) {
    // Exception handling code
}
```

### Exception Handling Flow

```text
        Start
          |
       try block
          |
    Exception occurs?
       /       \
     No         Yes
     |           |
 Continue      throw
 normal         |
 execution   catch block
     |           |
     |       Handle error
     |           |
     -------> Continue
```

## 3. Throwing and Catching an Exception

The `throw` keyword is used to generate an exception, and the `catch` block handles it.

### Example: Division by Zero

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 0;

    try {
        if (b == 0) {
            throw b;
        }

        cout << "Result: " << a / b << endl;
    }
    catch (int e) {
        cout << "Error: Division by zero is not allowed"
             << endl;
    }

    cout << "Program continues..." << endl;

    return 0;
}
```

**Output:**

```text
Error: Division by zero is not allowed
Program continues...
```

### Explanation

1. The program enters the `try` block.
2. The condition checks whether the denominator is zero.
3. `throw b` generates an exception.
4. The matching `catch(int e)` block receives it.
5. The error message is displayed.
6. The program continues after the catch block.

## 4. Multiple Catch Blocks

A single `try` block can have multiple `catch` blocks to handle different exception types.

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    try {
        int choice;
        cout << "Enter choice: ";
        cin >> choice;

        if (choice == 1)
            throw 100;

        else if (choice == 2)
            throw 10.5;

        else if (choice == 3)
            throw "Invalid operation";

        else
            cout << "No exception occurred" << endl;
    }
    catch (int e) {
        cout << "Integer exception: " << e << endl;
    }
    catch (double e) {
        cout << "Double exception: " << e << endl;
    }
    catch (const char* e) {
        cout << "String exception: " << e << endl;
    }

    return 0;
}
```

**Sample Output 1:**

```text
Enter choice: 1
Integer exception: 100
```

**Sample Output 2:**

```text
Enter choice: 2
Double exception: 10.5
```

**Sample Output 3:**

```text
Enter choice: 3
String exception: Invalid operation
```

## 5. Catch-All Handler

A catch-all handler is used to handle exceptions of any type that are not handled by earlier catch blocks.

It uses `catch(...)`.

### Syntax

```cpp
try {
    // Code
}
catch (...) {
    // Handle any exception
}
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    try {
        throw 100.5f;
    }
    catch (int e) {
        cout << "Integer exception" << endl;
    }
    catch (...) {
        cout << "Unknown exception caught" << endl;
    }

    return 0;
}
```

**Output:**

```text
Unknown exception caught
```

**Important:** The catch-all handler should generally be placed after the specific catch handlers.

## 6. Re-throwing an Exception

Re-throwing means throwing an already caught exception again so that another handler higher in the calling hierarchy can handle it.

The `throw;` statement is used to re-throw the currently handled exception.

### Example

```cpp
#include <iostream>
using namespace std;

void checkNumber(int num) {
    try {
        if (num < 0) {
            throw num;
        }
    }
    catch (int e) {
        cout << "Exception caught in function: "
             << e << endl;

        throw;
    }
}

int main() {
    try {
        checkNumber(-10);
    }
    catch (int e) {
        cout << "Exception caught in main: "
             << e << endl;
    }

    return 0;
}
```

**Output:**

```text
Exception caught in function: -10
Exception caught in main: -10
```

### Explanation

1. `checkNumber()` throws an integer exception.
2. Its local catch block handles the exception.
3. `throw;` re-throws the same exception.
4. The exception travels back to `main()`.
5. The catch block in `main()` handles it.

**Important:** A bare `throw;` should be used inside an active catch handler. Using it when no exception is being handled causes program termination.

## 7. Exception Propagation

Exception propagation means transferring an exception from the function where it occurs to the calling function until a matching handler is found.

### Example

```cpp
#include <iostream>
using namespace std;

void function3() {
    throw 100;
}

void function2() {
    function3();
}

void function1() {
    function2();
}

int main() {
    try {
        function1();
    }
    catch (int e) {
        cout << "Exception handled in main: "
             << e << endl;
    }

    return 0;
}
```

**Output:**

```text
Exception handled in main: 100
```

### Flow

```text
main()
  |
function1()
  |
function2()
  |
function3()
  |
throw 100
  |
Exception propagates backward
  |
main() catch block
```

## 8. Exception Specifications

Exception specifications describe which exceptions a function is allowed or expected to propagate.

### Modern C++: noexcept

In modern C++, `noexcept` is used to specify that a function is not expected to throw exceptions.

### Syntax

```cpp
void display() noexcept {
    // Function should not throw exceptions
}
```

### Example

```cpp
#include <iostream>
using namespace std;

void display() noexcept {
    cout << "This function is noexcept" << endl;
}

int main() {
    display();

    return 0;
}
```

**Output:**

```text
This function is noexcept
```

**Important Points:**

- `noexcept` is used in modern C++.
- It indicates that a function will not allow exceptions to escape.
- If an exception escapes a `noexcept` function, `std::terminate()` is called.
- Use it only when the function genuinely guarantees not to throw.

### Old Dynamic Exception Specifications

Older C++ versions supported declarations such as:

```cpp
void display() throw(int);
```

This syntax was deprecated in C++11 and removed in C++17.

For C++17 programming, prefer `noexcept` where appropriate.

## 9. Standard Exceptions in C++

C++ provides predefined exception classes through the standard library.

Most standard exception classes are derived from `std::exception`.

### Common Standard Exceptions

| Exception | Description |
|---|---|
| `std::exception` | Base class for standard exceptions |
| `std::runtime_error` | Runtime-related error |
| `std::logic_error` | Logical error in program |
| `std::out_of_range` | Accessing an element outside a valid range |
| `std::invalid_argument` | Invalid function argument |
| `std::bad_alloc` | Memory allocation failure |
| `std::overflow_error` | Arithmetic overflow |
| `std::underflow_error` | Arithmetic underflow |

### Example: Standard Exception

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

int main() {
    try {
        throw invalid_argument("Invalid age entered");
    }
    catch (const exception& e) {
        cout << "Exception: " << e.what() << endl;
    }

    return 0;
}
```

**Output:**

```text
Exception: Invalid age entered
```

### Explanation

- `invalid_argument` is a standard exception class.
- `what()` returns a description of the exception.
- Catching by `const exception&` can handle different standard exception types.

## 10. Custom Exception Class

A **custom exception** is a user-defined exception class created to handle application-specific errors.

It is useful when predefined exceptions do not clearly describe the error in your application.

### Example: Invalid Age Exception

```cpp
#include <iostream>
#include <exception>
using namespace std;

class InvalidAgeException : public exception {
public:
    const char* what() const noexcept override {
        return "Age must be 18 or above";
    }
};

int main() {
    int age;

    cout << "Enter age: ";
    cin >> age;

    try {
        if (age < 18) {
            throw InvalidAgeException();
        }

        cout << "Eligible for registration" << endl;
    }
    catch (const InvalidAgeException& e) {
        cout << "Error: " << e.what() << endl;
    }

    return 0;
}
```

**Sample Output 1:**

```text
Enter age: 15
Error: Age must be 18 or above
```

**Sample Output 2:**

```text
Enter age: 22
Eligible for registration
```

### Explanation

1. `InvalidAgeException` is a user-defined class.
2. It inherits from `std::exception`.
3. It overrides the `what()` function.
4. An object of the custom exception is thrown.
5. The matching catch block handles it.

## 11. Lab Work 1 – Exception Management

### Problem Statement

Implement exceptions and perform proper exception management throughout your program.

### Example: Bank Account Management

**Requirements:**

- Create a bank account.
- Deposit money.
- Withdraw money.
- Handle invalid deposit amounts.
- Handle insufficient balance.
- Handle invalid withdrawal amounts.

### Implementation

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    BankAccount(double amount) : balance(amount) {
        if (amount < 0) {
            throw invalid_argument(
                "Initial balance cannot be negative"
            );
        }
    }

    void deposit(double amount) {
        if (amount <= 0) {
            throw invalid_argument(
                "Deposit amount must be positive"
            );
        }

        balance += amount;
        cout << "Amount deposited successfully" << endl;
    }

    void withdraw(double amount) {
        if (amount <= 0) {
            throw invalid_argument(
                "Withdrawal amount must be positive"
            );
        }

        if (amount > balance) {
            throw runtime_error(
                "Insufficient account balance"
            );
        }

        balance -= amount;
        cout << "Withdrawal successful" << endl;
    }

    void displayBalance() const {
        cout << "Current Balance: "
             << balance << endl;
    }
};

int main() {
    try {
        BankAccount account(10000);

        account.deposit(2000);
        account.withdraw(3000);

        account.displayBalance();

        account.withdraw(15000);
    }
    catch (const exception& e) {
        cout << "Error: " << e.what() << endl;
    }

    return 0;
}
```

**Output:**

```text
Amount deposited successfully
Withdrawal successful
Current Balance: 9000
Error: Insufficient account balance
```

### Concepts Used

| Concept | Implementation |
|---|---|
| Exception Handling | `try` and `catch` |
| Throwing | `throw` |
| Standard Exceptions | `invalid_argument`, `runtime_error` |
| Exception Handling | Catching through `const exception&` |
| Encapsulation | Private balance member |
| Validation | Deposit and withdrawal checks |

## 12. Lab Work 2 – Custom Exception Class

### Problem Statement

Create a custom exception class and use it to handle application-specific errors.

### Example: Student Marks Validation

**Requirements:**

- Accept student marks.
- Marks must be between 0 and 100.
- Throw a custom exception for invalid marks.
- Display an appropriate error message.

### Implementation

```cpp
#include <iostream>
#include <exception>
using namespace std;

class InvalidMarksException : public exception {
public:
    const char* what() const noexcept override {
        return "Marks must be between 0 and 100";
    }
};

class Student {
private:
    int marks;

public:
    void setMarks(int m) {
        if (m < 0 || m > 100) {
            throw InvalidMarksException();
        }

        marks = m;
    }

    void display() const {
        cout << "Student Marks: " << marks << endl;
    }
};

int main() {
    Student s;
    int marks;

    cout << "Enter marks: ";
    cin >> marks;

    try {
        s.setMarks(marks);
        s.display();
    }
    catch (const InvalidMarksException& e) {
        cout << "Error: " << e.what() << endl;
    }

    return 0;
}
```

**Sample Output 1:**

```text
Enter marks: 85
Student Marks: 85
```

**Sample Output 2:**

```text
Enter marks: 120
Error: Marks must be between 0 and 100
```

## 13. Best Practices for Exception Handling

- Use exceptions for exceptional situations, not normal program flow.
- Catch exceptions by `const` reference when appropriate.
- Catch specific exceptions before general exceptions.
- Avoid empty catch blocks.
- Use standard exception classes when suitable.
- Create custom exceptions for application-specific errors.
- Use `throw;` to re-throw an exception from an active catch block.
- Do not allow exceptions to escape `noexcept` functions.
- Use RAII and standard library containers to manage resources safely.
- Avoid using exceptions as a replacement for input validation.
