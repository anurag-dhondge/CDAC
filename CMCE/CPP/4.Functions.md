# 1. Functions in C++

**Definition:** A function is a block of code that performs a specific task. It executes when it is called.

### Why Do We Need Functions?

- Code reusability.
- Reduces code duplication.
- Improves readability.
- Makes debugging easier.
- Divides large programs into smaller modules.

### Basic Syntax

```cpp
return_type function_name(parameters) {
    // Function body
    return value;
}
```

### Example

```cpp
#include <iostream>
using namespace std;

void greet() {
    cout << "Hello Anurag!";
}

int main() {
    greet();

    return 0;
}
```

**Output:**
```text
Hello Anurag!
```

**Simple Meaning:** A function is a reusable block of code designed to perform a particular task.

# 2. Different Forms of Functions

Functions can be classified based on whether they accept arguments and whether they return a value.

### Four Forms of Functions

| No. | Function Type | Arguments | Return Value |
|---|---|---|---|
| 1 | No arguments, No return value | No | No |
| 2 | Arguments, No return value | Yes | No |
| 3 | No arguments, With return value | No | Yes |
| 4 | Arguments, With return value | Yes | Yes |

## 2.1 No Arguments and No Return Value

**Definition:** A function that neither accepts arguments nor returns a value.

```cpp
#include <iostream>
using namespace std;

void add() {
    int a = 10, b = 20;
    cout << "Sum = " << a + b;
}

int main() {
    add();

    return 0;
}
```

**Output:**
```text
Sum = 30
```

**Simple Meaning:** No input and no returned output.

---

## 2.2 Arguments and No Return Value

**Definition:** A function that accepts arguments but does not return any value.

```cpp
#include <iostream>
using namespace std;

void add(int a, int b) {
    cout << "Sum = " << a + b;
}

int main() {
    add(10, 20);

    return 0;
}
```

**Output:**
```text
Sum = 30
```

**Simple Meaning:** Accepts input but does not return a value.

---

## 2.3 No Arguments and With Return Value

**Definition:** A function that does not accept arguments but returns a value.

```cpp
#include <iostream>
using namespace std;

int add() {
    int a = 10, b = 20;
    return a + b;
}

int main() {
    int result = add();

    cout << "Sum = " << result;

    return 0;
}
```

**Output:**
```text
Sum = 30
```

**Simple Meaning:** No input, but returns a value.

---

## 2.4 Arguments and With Return Value

**Definition:** A function that accepts arguments and returns a value.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}
```

**Output:**
```text
Sum = 30
```

**Simple Meaning:** Accepts input and returns a result.

# 3. Function Prototyping

**Definition:** A function prototype is a declaration that informs the compiler about a function's name, return type, and parameters before the function is used.

It allows us to call a function before its actual definition.

### Syntax

```cpp
return_type function_name(parameter_list);
```

### Example

```cpp
#include <iostream>
using namespace std;

// Function Prototype
int add(int, int);

int main() {
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}

// Function Definition
int add(int a, int b) {
    return a + b;
}
```

**Output:**
```text
Sum = 30
```

### Important Terms

| Term | Meaning |
|---|---|
| Function Declaration | Introduces a function to the compiler. |
| Function Prototype | Specifies return type, name and parameter types. |
| Function Call | Executes the function. |
| Function Definition | Contains the actual implementation. |

**Simple Meaning:** Function prototyping tells the compiler about a function before it is called.

# 4. Call by Reference

**Definition:** Call by reference passes a reference to the original variable instead of creating a separate copy.

Changes made inside the function affect the original variable.

### Example

```cpp
#include <iostream>
using namespace std;

void change(int &x) {
    x = 100;
}

int main() {
    int a = 10;

    cout << "Before: " << a << endl;

    change(a);

    cout << "After: " << a << endl;

    return 0;
}
```

**Output:**
```text
Before: 10
After: 100
```

### Understanding `&`

```cpp
void change(int &x)
```

Here, `x` is a reference to the original variable.

It does not create an independent copy.

---

## 4.1 Call by Value vs Call by Reference

| Call by Value | Call by Reference |
|---|---|
| Passes a copy of the variable. | Passes a reference to the original variable. |
| Changes do not affect the original variable. | Changes affect the original variable. |
| Uses separate parameter storage. | Parameter refers to the original object. |
| `void fun(int x)` | `void fun(int &x)` |

### Example – Call by Value

```cpp
#include <iostream>
using namespace std;

void change(int x) {
    x = 100;
}

int main() {
    int a = 10;

    change(a);

    cout << a;

    return 0;
}
```

**Output:**
```text
10
```

### Example – Call by Reference

```cpp
#include <iostream>
using namespace std;

void change(int &x) {
    x = 100;
}

int main() {
    int a = 10;

    change(a);

    cout << a;

    return 0;
}
```

**Output:**
```text
100
```

**Simple Meaning:** Call by reference allows a function to modify the original variable.

# 5. Inline Functions

**Definition:** An inline function is a function declared using the `inline` keyword. It allows the compiler to consider replacing a function call with the function's code to reduce function-call overhead.

**Syntax:**

```cpp
inline return_type function_name(parameters) {
    // Statements
}
```

### Example

```cpp
#include <iostream>
using namespace std;

inline int square(int n) {
    return n * n;
}

int main() {
    cout << "Square = " << square(5);

    return 0;
}
```

**Output:**
```text
Square = 25
```

### Advantages of Inline Functions

- May reduce function-call overhead.
- Useful for small functions.
- Improves code readability compared with repeated expressions.
- Avoids writing the same small code repeatedly.

### Important Points

- `inline` is a request or permission to the compiler, not a guarantee of actual inlining.
- The compiler decides whether to inline a function.
- Large or complex functions are generally not suitable candidates.
- Functions defined inside a class definition are implicitly inline.

**Simple Meaning:** An inline function allows the compiler to consider inserting function code directly at the calling location.

# 6. Math Library Functions

C++ provides mathematical functions through the `<cmath>` header file.

These functions help perform mathematical calculations easily.

### Header File

```cpp
#include <cmath>
```

### Common Math Library Functions

| Function | Description | Example | Result |
|---|---|---|---|
| `sqrt()` | Square root | `sqrt(25)` | 5 |
| `pow()` | Power | `pow(2, 3)` | 8 |
| `ceil()` | Rounds upward | `ceil(4.2)` | 5 |
| `floor()` | Rounds downward | `floor(4.8)` | 4 |
| `abs()` | Absolute value | `abs(-10)` | 10 |
| `round()` | Rounds to nearest integer | `round(4.6)` | 5 |
| `sin()` | Sine | `sin(0)` | 0 |
| `cos()` | Cosine | `cos(0)` | 1 |
| `tan()` | Tangent | `tan(0)` | 0 |
| `log()` | Natural logarithm | `log(1)` | 0 |
| `log10()` | Base-10 logarithm | `log10(100)` | 2 |
| `exp()` | Exponential function | `exp(0)` | 1 |

### Example

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << "Square Root: " << sqrt(25) << endl;

    cout << "Power: " << pow(2, 3) << endl;

    cout << "Ceil: " << ceil(4.2) << endl;

    cout << "Floor: " << floor(4.8) << endl;

    cout << "Absolute: " << abs(-10) << endl;

    return 0;
}
```

**Output:**
```text
Square Root: 5
Power: 8
Ceil: 5
Floor: 4
Absolute: 10
```

**Simple Meaning:** The `<cmath>` library provides ready-made mathematical functions.
