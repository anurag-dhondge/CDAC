## 1. Introduction to Console I/O

**Console I/O (Input/Output)** refers to the process of accepting input from the keyboard and displaying output on the screen.

C++ provides the following standard objects for console operations:

| Object | Purpose |
|---|---|
| `cin` | Reads input from keyboard |
| `cout` | Displays output on screen |
| `cerr` | Displays error messages |
| `clog` | Displays logging or diagnostic messages |

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;

    cout << "Enter your age: ";
    cin >> age;

    cout << "Your age is: " << age << endl;

    return 0;
}
```

**Output:**

```text
Enter your age: 22
Your age is: 22
```

### Error and Log Streams

```cpp
#include <iostream>
using namespace std;

int main() {
    cerr << "This is an error message" << endl;

    clog << "This is a log message" << endl;

    return 0;
}
```

**Output:**

```text
This is an error message
This is a log message
```

## 2. C++ Streams

A **stream** is a sequence of bytes or characters flowing between a program and an input/output device.

C++ uses streams to perform input and output operations.

### Types of Streams

| Stream | Description |
|---|---|
| Input Stream | Transfers data into the program |
| Output Stream | Transfers data from the program |
| Input/Output Stream | Supports both input and output |

### Stream Flow

```text
          Input Stream
Keyboard -------------> Program
                            |
                            |
                         Output Stream
                            |
                            v
                          Screen
```

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    int num;

    // Input stream
    cin >> num;

    // Output stream
    cout << "Number: " << num << endl;

    return 0;
}
```

## 3. C++ Stream Classes

C++ provides different stream classes through the `<iostream>` and `<fstream>` libraries.

### Important Stream Classes

| Class | Description |
|---|---|
| `ios` | Base class for stream classes |
| `istream` | Input stream class |
| `ostream` | Output stream class |
| `iostream` | Supports both input and output |
| `ifstream` | Reads data from files |
| `ofstream` | Writes data to files |
| `fstream` | Reads and writes files |

### Stream Class Hierarchy

```text
                 ios_base
                    |
                   ios
                    |
          ---------------------
          |                   |
       istream              ostream
          |                   |
       ifstream             ofstream
          \                   /
           \                 /
                 fstream
```

**Note:** This is a simplified conceptual diagram. `fstream` provides both input and output capabilities through the stream class hierarchy.

### Example

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fout("demo.txt");

    fout << "Welcome to C++ File Handling";

    fout.close();

    cout << "Data written successfully";

    return 0;
}
```

## 4. Unformatted I/O Operations

**Unformatted I/O** operations read or write characters and data without applying formatted field conversion.

### Important Unformatted I/O Functions

| Function | Description |
|---|---|
| `get()` | Reads a character |
| `getline()` | Reads a complete line |
| `put()` | Writes a character |
| `read()` | Reads a block of bytes |
| `write()` | Writes a block of bytes |
| `ignore()` | Skips characters from input |
| `peek()` | Checks the next character without extracting it |
| `putback()` | Puts a character back into the input stream |
| `unget()` | Moves the input position back by one character |

### 4.1 get()

Reads a single character from the input stream.

```cpp
#include <iostream>
using namespace std;

int main() {
    char ch;

    cout << "Enter a character: ";
    cin.get(ch);

    cout << "Character: ";
    cout.put(ch);

    return 0;
}
```

**Output:**

```text
Enter a character: A
Character: A
```

### 4.2 getline()

Reads an entire line, including spaces.

```cpp
#include <iostream>
using namespace std;

int main() {
    char name[100];

    cout << "Enter your full name: ";
    cin.getline(name, 100);

    cout << "Name: " << name;

    return 0;
}
```

**Output:**

```text
Enter your full name: Anurag Dhondge
Name: Anurag Dhondge
```

### 4.3 put()

Writes a single character to the output stream.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout.put('A');
    cout.put('\n');
    cout.put('B');

    return 0;
}
```

**Output:**

```text
A
B
```

### 4.4 read() and write()

Used to read and write blocks of bytes.

```cpp
#include <iostream>
using namespace std;

int main() {
    char data[] = "Hello C++";

    cout.write(data, 9);

    return 0;
}
```

**Output:**

```text
Hello C++
```

## 5. Formatted I/O Operations

**Formatted I/O** allows data to be displayed or accepted in a specified format.

C++ provides formatting functions and manipulators to control the appearance of input and output.

### Important Formatting Functions

| Function | Description |
|---|---|
| `width()` | Sets the minimum field width |
| `precision()` | Sets floating-point precision |
| `fill()` | Sets the padding character |
| `setf()` | Sets formatting flags |
| `unsetf()` | Clears formatting flags |

### Example

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 123.456789;

    cout.precision(4);
    cout << num << endl;

    cout.width(10);
    cout << 100 << endl;

    cout.fill('*');
    cout.width(10);
    cout << 100 << endl;

    return 0;
}
```

**Output:**

```text
123.5
       100
*******100
```

## 6. Managing Output with Manipulators

**Manipulators** are special functions used to control the formatting of input and output streams.

The `<iomanip>` header provides several useful manipulators.

### Important Manipulators

| Manipulator | Purpose |
|---|---|
| `endl` | Inserts a newline and flushes the stream |
| `setw(n)` | Sets field width |
| `setprecision(n)` | Sets floating-point precision |
| `setfill(ch)` | Sets the fill character |
| `fixed` | Displays floating-point values in fixed notation |
| `scientific` | Displays values in scientific notation |
| `left` | Left-aligns output |
| `right` | Right-aligns output |
| `hex` | Displays integers in hexadecimal |
| `oct` | Displays integers in octal |
| `dec` | Displays integers in decimal |
| `showpoint` | Forces decimal point display |
| `boolalpha` | Displays Boolean values as true or false |

### Example: setw(), setprecision() and setfill()

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double price = 123.456789;

    cout << fixed << setprecision(2);

    cout << "Price: " << price << endl;

    cout << setfill('*') << setw(10) << 100 << endl;

    return 0;
}
```

**Output:**

```text
Price: 123.46
*******100
```

### Example: Number System Manipulators

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 255;

    cout << "Decimal: " << dec << num << endl;
    cout << "Hexadecimal: " << hex << num << endl;
    cout << "Octal: " << oct << num << endl;

    return 0;
}
```

**Output:**

```text
Decimal: 255
Hexadecimal: ff
Octal: 377
```

### Example: Boolean Manipulator

```cpp
#include <iostream>
using namespace std;

int main() {
    bool status = true;

    cout << status << endl;
    cout << boolalpha << status << endl;

    return 0;
}
```

**Output:**

```text
1
true
```

## 7. Definition of File

A **file** is a collection of data stored permanently on a storage device such as a hard disk or SSD.

Files allow data to remain available even after a program terminates.

### Why Do We Need Files?

- To store information permanently.
- To retrieve previously stored data.
- To maintain records.
- To share information between programs.
- To process large amounts of data.

### Types of Files

| Type | Description |
|---|---|
| Text File | Stores data in readable character format |
| Binary File | Stores data as bytes in binary representation |

### Text File Example

```text
Student Details
Name: Anurag
Roll No: 101
Marks: 85
```

### Binary File

A binary file stores data in binary form and is not generally human-readable as plain text.

## 8. File Handling in C++

C++ provides the `<fstream>` header to perform file operations.

### File Stream Classes

| Class | Purpose |
|---|---|
| `ifstream` | Input file stream – reads files |
| `ofstream` | Output file stream – writes files |
| `fstream` | Input and output file stream |

### Basic File Handling Steps

1. Include the `<fstream>` header.
2. Create a file stream object.
3. Open the file.
4. Perform read or write operations.
5. Close the file.

### Syntax

```cpp
#include <fstream>

ofstream fout("file.txt");  // Write
ifstream fin("file.txt");   // Read
fstream file("file.txt");   // Read and write
```

## 9. Writing Data into a File

The `ofstream` class is used to write data into a file.

### Example

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fout("student.txt");

    if (!fout) {
        cout << "File opening failed";
        return 1;
    }

    fout << "Name: Anurag" << endl;
    fout << "Roll No: 101" << endl;
    fout << "Course: PGCP-AC" << endl;

    fout.close();

    cout << "Data written successfully";

    return 0;
}
```

**Output:**

```text
Data written successfully
```

**Contents of student.txt:**

```text
Name: Anurag
Roll No: 101
Course: PGCP-AC
```

## 10. Reading Data from a File

The `ifstream` class is used to read data from an existing file.

### Example

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream fin("student.txt");

    if (!fin) {
        cout << "Unable to open file";
        return 1;
    }

    string line;

    while (getline(fin, line)) {
        cout << line << endl;
    }

    fin.close();

    return 0;
}
```

**Output:**

```text
Name: Anurag
Roll No: 101
Course: PGCP-AC
```

### Explanation

- `ifstream` opens the file for reading.
- `getline()` reads one line at a time.
- The `while` loop continues until the end of the file.
- `close()` closes the file.

## 11. File Opening Modes

C++ provides different file opening modes to control how files are accessed.

### Important File Modes

| Mode | Description |
|---|---|
| `ios::in` | Opens a file for reading |
| `ios::out` | Opens a file for writing |
| `ios::app` | Appends data at the end |
| `ios::ate` | Opens a file and initially positions at the end |
| `ios::trunc` | Discards existing file contents when opening |
| `ios::binary` | Opens a file in binary mode |

### Example: Append Data

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fout("student.txt", ios::app);

    if (!fout) {
        cout << "File opening failed";
        return 1;
    }

    fout << "City: Pune" << endl;

    fout.close();

    cout << "Data appended successfully";

    return 0;
}
```

**Updated Contents of student.txt:**

```text
Name: Anurag
Roll No: 101
Course: PGCP-AC
City: Pune
```

### Combining File Modes

Multiple modes can be combined using the bitwise OR operator `|`.

```cpp
fstream file("data.txt", ios::in | ios::out);
```

## 12. Reading and Writing Using fstream

The `fstream` class supports both reading and writing operations.

### Example

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    fstream file(
        "data.txt",
        ios::in | ios::out | ios::trunc
    );

    if (!file) {
        cout << "File opening failed";
        return 1;
    }

    file << "Welcome to C++ File Handling";

    file.seekg(0);

    string line;
    getline(file, line);

    cout << "File Data: " << line << endl;

    file.close();

    return 0;
}
```

**Output:**

```text
File Data: Welcome to C++ File Handling
```

### Important File Position Functions

| Function | Description |
|---|---|
| `seekg()` | Moves the input/get position |
| `seekp()` | Moves the output/put position |
| `tellg()` | Returns the current input position |
| `tellp()` | Returns the current output position |

## 13. Binary File Handling

Binary file handling stores and reads data in binary format.

The `ios::binary` mode is used to open a file in binary mode.

### Example: Write and Read Binary Data

```cpp
#include <iostream>
#include <fstream>
using namespace std;

class Student {
public:
    int roll;
    char name[30];
};

int main() {
    Student s1 = {101, "Anurag"};
    Student s2;

    // Writing binary data
    ofstream fout("student.dat", ios::binary);

    if (!fout) {
        cout << "Unable to create file";
        return 1;
    }

    fout.write(
        reinterpret_cast<const char*>(&s1),
        sizeof(s1)
    );

    fout.close();

    // Reading binary data
    ifstream fin("student.dat", ios::binary);

    if (!fin) {
        cout << "Unable to read file";
        return 1;
    }

    fin.read(
        reinterpret_cast<char*>(&s2),
        sizeof(s2)
    );

    if (fin) {
        cout << "Roll No: " << s2.roll << endl;
        cout << "Name: " << s2.name << endl;
    }

    fin.close();

    return 0;
}
```

**Output:**

```text
Roll No: 101
Name: Anurag
```

**Important:** This example is suitable for a simple class containing fixed-size fields. Do not directly write arbitrary objects containing `string`, pointers, virtual functions, or other non-trivially-copyable members as raw bytes. Such objects need proper serialization.

## 14. File Error Handling

Always check whether a file has opened successfully before performing file operations.

### Important File State Functions

| Function | Description |
|---|---|
| `is_open()` | Checks whether the file is open |
| `good()` | Checks whether no error flags are set |
| `eof()` | Checks whether end-of-file has been reached |
| `fail()` | Checks whether an operation failed |
| `bad()` | Checks for a serious stream error |
| `clear()` | Clears stream error flags |
| `close()` | Closes the file |

### Example

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream fin("unknown.txt");

    if (!fin.is_open()) {
        cout << "File does not exist or cannot be opened";
        return 1;
    }

    cout << "File opened successfully";

    fin.close();

    return 0;
}
```

**Possible Output:**

```text
File does not exist or cannot be opened
```
