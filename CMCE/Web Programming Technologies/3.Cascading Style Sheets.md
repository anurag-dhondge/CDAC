## 1. Introduction to CSS

### 1.1 What is CSS?

CSS stands for **Cascading Style Sheets**.

CSS is a stylesheet language used to describe the presentation and layout of HTML documents.

HTML defines the structure and content of a webpage, whereas CSS controls how that content looks.

**Example:**

HTML:
```html
<h1>Hello World</h1>
<p>Welcome to CSS.</p>
```

CSS:
```css
h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
    color: gray;
}
```

### 1.2 Why do we use CSS?

Without CSS, webpages mostly display using the browser's default styles.

CSS helps us:

1. Change text color, size, and font.
2. Add backgrounds, borders, and shadows.
3. Control spacing and alignment.
4. Create responsive layouts.
5. Arrange elements using Flexbox and Grid.
6. Maintain a consistent design across multiple webpages.
7. Separate HTML structure from visual presentation.

### 1.3 CSS Syntax

A CSS rule consists of a selector and a declaration block.

```css
selector {
    property: value;
}
```

Example:

```css
h1 {
    color: red;
    font-size: 32px;
}
```

Explanation:

- `h1`: Selector – selects all h1 elements.
- `color`: Property – defines the text color.
- `red`: Value – specifies the color.
- `font-size`: Property – defines the font size.
- `32px`: Value – specifies the size.

A CSS declaration consists of a property and its value.

### 1.4 Types of CSS Selectors

| Selector | Example | Purpose |
|---|---|---|
| Element | `p` | Selects all paragraph elements |
| ID | `#header` | Selects an element with a particular ID |
| Class | `.container` | Selects elements belonging to a class |
| Universal | `*` | Selects all elements |
| Group | `h1, p` | Selects multiple elements |
| Descendant | `.box p` | Selects paragraphs inside `.box` |
| Child | `.box > p` | Selects direct child paragraphs |
| Pseudo-class | `a:hover` | Selects an element in a particular state |

Example:

```css
* {
    box-sizing: border-box;
}

h1 {
    color: navy;
}

#main-title {
    text-align: center;
}

.highlight {
    background-color: yellow;
}

h1, p {
    font-family: Arial, sans-serif;
}
```

## 2. Inline CSS, Internal CSS, External CSS

There are three common ways to apply CSS to HTML documents.

### 2.1 Inline CSS

Inline CSS is written directly inside an HTML element using the `style` attribute.

Example:

```html
<h1 style="color: blue; text-align: center;">
    Welcome to CSS
</h1>

<p style="font-size: 18px; color: green;">
    This is an example of inline CSS.
</p>
```

Advantages:
- Quick to apply.
- Useful for testing individual styles.
- Does not require a separate stylesheet.

Disadvantages:
- Difficult to maintain.
- Repeated styles create duplication.
- Not suitable for large applications.
- Mixes presentation with HTML structure.

### 2.2 Internal CSS

Internal CSS is written inside the `<style>` element, generally within the `<head>` section of an HTML document.

Example:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Internal CSS</title>

    <style>
        h1 {
            color: blue;
            text-align: center;
        }

        p {
            font-size: 18px;
            color: green;
        }
    </style>
</head>
<body>

    <h1>Welcome to CSS</h1>
    <p>This webpage uses internal CSS.</p>

</body>
</html>
```

Advantages:
- Styles are organized in one place.
- Useful for styling a single webpage.
- No separate CSS file is required.

Disadvantages:
- Cannot be reused automatically across multiple pages.
- HTML file becomes longer.
- Maintenance becomes difficult for larger websites.

### 2.3 External CSS

External CSS is written in a separate `.css` file and connected to HTML using the `<link>` element.

**HTML file – index.html**

```html
<!DOCTYPE html>
<html>
<head>
    <title>External CSS</title>

    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1>Welcome to CSS</h1>
    <p>This webpage uses external CSS.</p>

</body>
</html>
```

**CSS file – style.css**

```css
h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
    color: green;
}
```

Advantages:
- Reusable across multiple HTML pages.
- Easier to maintain.
- Keeps HTML clean.
- Suitable for large projects.

Disadvantages:
- Requires a separate file.
- The browser must load the stylesheet.
- Incorrect file paths can prevent styles from loading.

### 2.4 Comparison of CSS Types

| Feature | Inline | Internal | External |
|---|---|---|---|
| Location | HTML element | `<style>` tag | `.css` file |
| Reusability | Low | Limited to page | High |
| Maintenance | Difficult | Moderate | Easy |
| Best use | Quick styling | Single page | Real projects |

**Important:** In practical web development, external CSS is generally preferred.

### 2.5 Which CSS takes priority?

When multiple CSS rules target the same element, the browser uses the CSS cascade.

The result depends on:
1. Origin and importance of the declarations.
2. Cascade layer and specificity.
3. Source order when other factors are equal.

For a basic example:

```html
<p id="message" class="text" style="color: red;">
    Hello CSS
</p>
```

```css
p {
    color: blue;
}

.text {
    color: green;
}

#message {
    color: purple;
}
```

The text appears red because the normal inline style takes precedence over these normal author stylesheet declarations.

**Important:** CSS priority is not simply a fixed order of inline, internal, and external CSS. Specificity, importance, cascade layers, and source order also matter. An `!important` declaration can change the result.

## 3. CSS Fonts

CSS provides properties to control the appearance of text.

### 3.1 Common Font Properties

| Property | Purpose | Example |
|---|---|---|
| `font-family` | Specifies font type | `Arial` |
| `font-size` | Specifies font size | `18px` |
| `font-weight` | Controls thickness | `bold` |
| `font-style` | Controls italic style | `italic` |
| `font-variant` | Controls small-caps display | `small-caps` |
| `line-height` | Controls line spacing | `1.5` |

### 3.2 font-family

Specifies the typeface used for text.

```css
body {
    font-family: Arial, Helvetica, sans-serif;
}
```

A fallback list is useful when the first font is unavailable.

### 3.3 font-size

Specifies the size of text.

```css
h1 {
    font-size: 32px;
}

p {
    font-size: 18px;
}
```

Common units:

- `px`: Pixels.
- `em`: Relative to the parent element's font size.
- `rem`: Relative to the root element's font size.
- `%`: Relative to the relevant inherited or parent sizing context.

### 3.4 font-weight

Controls the thickness of text.

```css
p {
    font-weight: normal;
}

h1 {
    font-weight: bold;
}

h2 {
    font-weight: 600;
}
```

Common values include `normal`, `bold`, and numeric values such as `100` to `900`, depending on the available font.

### 3.5 font-style

```css
.normal {
    font-style: normal;
}

.italic {
    font-style: italic;
}
```

### 3.6 Text Alignment

```css
.left {
    text-align: left;
}

.center {
    text-align: center;
}

.right {
    text-align: right;
}

.justify {
    text-align: justify;
}
```

### 3.7 Example: Applying Font Properties

```html
<!DOCTYPE html>
<html>
<head>
    <title>CSS Fonts</title>

    <style>
        body {
            font-family: Arial, sans-serif;
        }

        h1 {
            font-size: 32px;
            font-weight: bold;
            color: navy;
            text-align: center;
        }

        p {
            font-size: 18px;
            font-style: italic;
            line-height: 1.6;
        }
    </style>
</head>
<body>

    <h1>CSS Font Example</h1>
    <p>CSS provides several properties to style text.</p>

</body>
</html>
```

## 4. CSS Box Model

### 4.1 What is the CSS Box Model?

Every HTML element is treated as a rectangular box by the browser.

The CSS Box Model describes how the size of an element is calculated using four areas:

1. Content
2. Padding
3. Border
4. Margin

### 4.2 Box Model Structure

```text
+-----------------------------------------+
|                 MARGIN                  |
|  +-----------------------------------+  |
|  |              BORDER               |  |
|  |  +-----------------------------+  |  |
|  |  |           PADDING           |  |  |
|  |  |  +-----------------------+  |  |  |
|  |  |  |        CONTENT        |  |  |  |
|  |  |  +-----------------------+  |  |  |
|  |  +-----------------------------+  |  |
|  +-----------------------------------+  |
+-----------------------------------------+
```

### 4.3 Content

The actual content of an element, such as text, images, or other HTML elements.

```css
.box {
    width: 200px;
    height: 100px;
}
```

### 4.4 Padding

Padding is the space between the content and the border.

```css
.box {
    padding: 20px;
}
```

Individual padding properties:

```css
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 10px;
    padding-left: 20px;
}
```

Shorthand:

```css
.box {
    padding: 10px 20px 10px 30px;
}
```

The order is top, right, bottom, left.

### 4.5 Border

Border surrounds the padding and content.

```css
.box {
    border: 2px solid black;
}
```

Individual properties:

```css
.box {
    border-width: 2px;
    border-style: solid;
    border-color: blue;
    border-radius: 10px;
}
```

### 4.6 Margin

Margin is the space outside the border. It separates an element from neighboring elements.

```css
.box {
    margin: 20px;
}
```

Center a block element horizontally when it has a defined width:

```css
.box {
    width: 300px;
    margin: 0 auto;
}
```

### 4.7 Box Model Calculation

Consider:

```css
.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}
```

With the default `content-box` sizing:

Total width excluding margins:

= Content width + Left and right padding + Left and right borders

= 200 + 40 + 10

= **250px**

Including margins:

= 250 + 20

= **270px**

### 4.8 box-sizing Property

CSS provides the `box-sizing` property to control how width and height are calculated.

**content-box (default):**

The specified width applies only to the content.

**border-box:**

The specified width includes content, padding, and border.

Example:

```css
* {
    box-sizing: border-box;
}

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
}
```

The total width remains 200px, excluding margins.

**Best practice:**

```css
*,
*::before,
*::after {
    box-sizing: border-box;
}
```

This makes layout calculations easier.

## 5. id and class Attributes

The HTML `id` and `class` attributes are used to identify elements so CSS and JavaScript can target them.

### 5.1 ID Attribute

An ID identifies one particular element within a document.

HTML:

```html
<h1 id="main-heading">Welcome</h1>
```

CSS:

```css
#main-heading {
    color: blue;
    text-align: center;
}
```

The `#` symbol is used to select an ID in CSS.

Important points:
- An ID should be unique within an HTML document.
- An element can have only one `id` attribute.
- IDs can be used as fragment identifiers in URLs.
- JavaScript can access an element by ID.

### 5.2 Class Attribute

A class is used to group multiple elements that share common styling.

HTML:

```html
<p class="highlight">First paragraph</p>
<p class="highlight">Second paragraph</p>
<p class="highlight">Third paragraph</p>
```

CSS:

```css
.highlight {
    color: red;
    background-color: yellow;
}
```

The `.` symbol is used to select a class in CSS.

Important points:
- Multiple elements can share the same class.
- An element can have multiple classes.
- Classes are reusable.

Example:

```html
<p class="text bold">Hello World</p>
```

```css
.text {
    color: blue;
}

.bold {
    font-weight: bold;
}
```

### 5.3 ID vs Class

| ID | Class |
|---|---|
| Uses `#` in CSS | Uses `.` in CSS |
| Should be unique | Can be reused |
| One ID attribute per element | Multiple class names can be used |
| Example: `id="header"` | Example: `class="container"` |

### 5.4 ID and Class Specificity

For basic author CSS rules, an ID selector has higher specificity than a class selector, which has higher specificity than an element selector.

Example:

```css
p {
    color: blue;
}

.message {
    color: green;
}

#notice {
    color: red;
}
```

```html
<p id="notice" class="message">
    CSS Specificity Example
</p>
```

The text appears red.

## 6. HTML Style Tags

There are two important ways of writing CSS in HTML.

### 6.1 The style Attribute

The `style` attribute applies CSS directly to one HTML element.

```html
<p style="color: red; font-size: 20px;">
    Inline CSS Example
</p>
```

### 6.2 The style Element

The `<style>` element contains CSS rules and is normally placed inside the `<head>` element.

```html
<head>
    <style>
        body {
            background-color: lightgray;
        }

        h1 {
            color: blue;
        }
    </style>
</head>
```

### 6.3 Difference Between style Attribute and style Element

| style Attribute | style Element |
|---|---|
| Written inside an HTML element | Written inside the HTML document |
| Applies to one element | Can style multiple elements |
| Used for inline CSS | Used for internal CSS |
| Example: `style="color:red"` | Example: `<style>p { color:red; }</style>` |

## 7. Linking Style Sheets

External CSS files are connected to HTML using the `<link>` element.

### 7.1 Syntax

```html
<link rel="stylesheet" href="style.css">
```

Explanation:

- `link`: HTML element used to link external resources.
- `rel="stylesheet"`: Specifies that the linked resource is a stylesheet.
- `href="style.css"`: Specifies the CSS file path.

### 7.2 Project Structure

```text
my-project/
│
├── index.html
│
└── css/
    └── style.css
```

HTML:

```html
<link rel="stylesheet" href="css/style.css">
```

### 7.3 Different CSS File Paths

Same folder:

```html
<link rel="stylesheet" href="style.css">
```

Inside a CSS folder:

```html
<link rel="stylesheet" href="css/style.css">
```

One directory above:

```html
<link rel="stylesheet" href="../style.css">
```

### 7.4 Multiple Stylesheets

You can link multiple CSS files.

```html
<link rel="stylesheet" href="reset.css">
<link rel="stylesheet" href="style.css">
<link rel="stylesheet" href="responsive.css">
```

When rules have equal cascade priority and specificity, later rules can override earlier ones.

## 8. CSS Flexbox

### 8.1 What is Flexbox?

Flexbox stands for **Flexible Box Layout**.

It is a CSS layout model used to arrange elements in a row or column and distribute available space between them.

Flexbox is especially useful for:
- Navigation bars.
- Cards.
- Centering content.
- Toolbars.
- Responsive one-dimensional layouts.

### 8.2 Flex Container and Flex Items

The parent element becomes a flex container when we apply:

```css
.container {
    display: flex;
}
```

Its direct children become flex items.

Example:

```html
<div class="container">
    <div class="item">One</div>
    <div class="item">Two</div>
    <div class="item">Three</div>
</div>
```

```css
.container {
    display: flex;
}

.item {
    padding: 20px;
    background-color: lightblue;
    border: 1px solid black;
}
```

### 8.3 Flexbox Axes

Flexbox uses two axes:

1. Main Axis – direction in which flex items are arranged.
2. Cross Axis – perpendicular to the main axis.

By default:
- Main axis: Horizontal.
- Cross axis: Vertical.

When `flex-direction: column` is used, the axes change accordingly.

### 8.4 flex-direction

Controls the direction of flex items.

```css
.container {
    display: flex;
    flex-direction: row;
}
```

Values:

| Value | Meaning |
|---|---|
| `row` | Left to right |
| `row-reverse` | Right to left |
| `column` | Top to bottom |
| `column-reverse` | Bottom to top |

### 8.5 justify-content

Aligns and distributes flex items along the main axis.

```css
.container {
    display: flex;
    justify-content: center;
}
```

Common values:

| Value | Purpose |
|---|---|
| `flex-start` | Items at the start |
| `flex-end` | Items at the end |
| `center` | Items centered |
| `space-between` | Equal space between items |
| `space-around` | Space around items |
| `space-evenly` | Equal space between and around items |

### 8.6 align-items

Aligns items along the cross axis.

```css
.container {
    display: flex;
    align-items: center;
}
```

Common values:
- `stretch`
- `flex-start`
- `flex-end`
- `center`
- `baseline`

### 8.7 flex-wrap

Controls whether flex items stay on one line or wrap onto multiple lines.

```css
.container {
    display: flex;
    flex-wrap: wrap;
}
```

Values:
- `nowrap`
- `wrap`
- `wrap-reverse`

### 8.8 gap

Adds spacing between flex items.

```css
.container {
    display: flex;
    gap: 20px;
}
```

### 8.9 flex Property

The `flex` shorthand controls how an item grows, shrinks, and uses its base size.

```css
.item {
    flex: 1;
}
```

A common example:

```css
.item {
    flex: 1 1 200px;
}
```

This means:
- Grow: 1
- Shrink: 1
- Basis: 200px

### 8.10 Complete Flexbox Example

```html
<!DOCTYPE html>
<html>
<head>
    <title>Flexbox Example</title>

    <style>
        .container {
            display: flex;
            flex-direction: row;
            justify-content: space-around;
            align-items: center;
            flex-wrap: wrap;
            gap: 15px;
            padding: 20px;
            background-color: lightgray;
        }

        .item {
            flex: 1 1 150px;
            padding: 30px;
            text-align: center;
            background-color: steelblue;
            color: white;
        }
    </style>
</head>
<body>

    <h1>CSS Flexbox</h1>

    <div class="container">
        <div class="item">Item 1</div>
        <div class="item">Item 2</div>
        <div class="item">Item 3</div>
    </div>

</body>
</html>
```

## 9. CSS Grid

### 9.1 What is CSS Grid?

CSS Grid is a two-dimensional CSS layout system.

It is used to arrange elements in rows and columns.

Grid is useful for:
- Webpage layouts.
- Dashboards.
- Image galleries.
- Product listings.
- Complex responsive layouts.

### 9.2 Grid Container and Grid Items

The parent becomes a grid container using:

```css
.container {
    display: grid;
}
```

Its direct children become grid items.

Example:

```html
<div class="container">
    <div class="item">One</div>
    <div class="item">Two</div>
    <div class="item">Three</div>
    <div class="item">Four</div>
</div>
```

```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
}

.item {
    padding: 30px;
    background-color: lightblue;
    text-align: center;
}
```

### 9.3 grid-template-columns

Defines the number and width of columns.

```css
.container {
    display: grid;
    grid-template-columns: 200px 200px;
}
```

This creates two columns of 200px each.

Using fractional units:

```css
.container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
}
```

This divides the available space into three columns in the ratio 1:2:1.

### 9.4 grid-template-rows

Defines the height of rows.

```css
.container {
    display: grid;
    grid-template-rows: 100px 200px;
}
```

### 9.5 gap

Defines the spacing between rows and columns.

```css
.container {
    display: grid;
    gap: 20px;
}
```

Separate values:

```css
.container {
    row-gap: 10px;
    column-gap: 20px;
}
```

### 9.6 repeat() Function

Avoids writing repeated column definitions.

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
```

Creates three equal-width columns.

### 9.7 minmax() Function

Specifies a minimum and maximum size for a grid track.

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, minmax(150px, 1fr));
}
```

### 9.8 auto-fit and auto-fill

These keywords help create responsive grid layouts.

```css
.container {
    display: grid;
    grid-template-columns: repeat(
        auto-fit,
        minmax(200px, 1fr)
    );
    gap: 20px;
}
```

The browser adjusts the number of columns according to available space.

### 9.9 grid-column and grid-row

These properties allow an item to occupy multiple grid tracks.

```css
.header {
    grid-column: 1 / 3;
}
```

The item starts at grid line 1 and ends at grid line 3, spanning two columns.

### 9.10 Complete Grid Example

```html
<!DOCTYPE html>
<html>
<head>
    <title>CSS Grid Example</title>

    <style>
        .container {
            display: grid;
            grid-template-columns: repeat(3, 1fr);
            gap: 15px;
        }

        .item {
            padding: 30px;
            background-color: steelblue;
            color: white;
            text-align: center;
        }

        .header {
            grid-column: 1 / 4;
        }
    </style>
</head>
<body>

    <h1>CSS Grid Layout</h1>

    <div class="container">
        <div class="item header">Header</div>
        <div class="item">Item 1</div>
        <div class="item">Item 2</div>
        <div class="item">Item 3</div>
    </div>

</body>
</html>
```

### 9.11 Flexbox vs Grid

| Flexbox | Grid |
|---|---|
| One-dimensional layout | Two-dimensional layout |
| Mainly row OR column | Rows AND columns |
| Good for navigation bars | Good for complete page layouts |
| Content-oriented arrangement | Layout-oriented arrangement |
| `display: flex` | `display: grid` |

**Remember:** Flexbox and Grid are not competitors. They are often used together in the same webpage.

# 10. LAB PRACTICAL 1: Apply Inline, Internal and External CSS to Style the Resume

## Objective

Create a resume webpage and apply all three types of CSS:
1. Inline CSS
2. Internal CSS
3. External CSS

## Project Structure

```text
resume-css/
│
├── index.html
└── style.css
```

## Step 1: Apply Inline CSS

Add inline styles to selected HTML elements.


```html

    body {
```

```css
.resume {
```

# 12. Responsive Design – Additional Concept

Responsive web design means creating webpages that adapt to different screen sizes and devices.

Common techniques:

1. Flexible layouts using Flexbox and Grid.
2. Relative units such as `%`, `rem`, and `fr`.
3. Responsive images.
4. CSS media queries.
5. Mobile-friendly viewport configuration.

Example:

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

@media (max-width: 768px) {
    .container {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (max-width: 480px) {
    .container {
        grid-template-columns: 1fr;
    }
}
```

The layout changes from three columns to two and then one column.
