# 🌐 CMCE – Web Programming Technologies
### Session 1: Architecture of Web

**Course:** PGCP-AC (CMCE)  
**Batch:** August 2026  
**Institute:** ACTS, Pune

## 📚 Topics Covered

1. **History and Working of the Internet**
   - Introduction to the Internet
   - Evolution and working of the Internet

2. **Internet Protocols**
   - Introduction to network protocols
   - Communication over the Internet

3. **Domain Names and DNS**
   - Domain Names
   - Domain Name System (DNS)
   - DNS Servers and name resolution

4. **HTTP Protocol**
   - HTTP Methods: GET, POST, HEAD, PUT, DELETE, etc.
   - HTTP Status Codes
   - Stateless Nature of HTTP
   - HTTP Sessions
   - HTTPS

5. **Web Architecture**
   - Architecture of the Web
   - Web Servers
   - IIS (Internet Information Services)
   - Apache Server

## 🎯 Learning Objectives

- Understand how the Internet and World Wide Web work.
- Learn how browsers and web servers communicate.
- Understand HTTP methods and status codes.
- Understand DNS and domain name resolution.
- Learn the fundamentals of web architecture and web servers.
