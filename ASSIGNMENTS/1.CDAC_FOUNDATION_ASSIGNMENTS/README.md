# 💻 Development Environment

The repository also contains setup information for developing and running **C/C++ programs using VS Code and MSYS2/MinGW**.

### Setup

1. Install **Visual Studio Code**.
2. Install **MSYS2**.
3. Install the **UCRT64 GCC toolchain**.
4. Add the following path to the system `PATH`:

```text
C:\msys64\ucrt64\bin
```

5. Verify the compiler installation using:

```bash
g++ --version
```

### VS Code Extensions

Recommended extensions:

* **C/C++** — Microsoft
* **Code Runner** — Jun Han

For programs requiring input through `scanf()` or `cin`, enable:

```text
Code Runner: Run In Terminal
```

in VS Code settings.
